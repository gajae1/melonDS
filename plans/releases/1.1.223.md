# 1.1.223 — Vulkan 소형 무텍스처 배치의 래스터·깊이 블렌드 융합

2026-09-29. SDL3·SDL2 패키지와 플랫폼 CI 검증을 완료했다.

## 변경

Vulkan 배치 처리는 span 준비와 타일 binning 뒤에 별도 간접 dispatch로 래스터 결과를 중간 ColorTiles/DepthTiles에 기록하고, 순서 보존 깊이·블렌드 셰이더가 이를 다시 읽어 합성했다. 1.1.223은 조건을 만족하는 배치에서 래스터 계산을 깊이·블렌드 셰이더 안으로 옮긴다. 폴리곤은 기존 순서대로 처리하고 블렌딩 규칙은 바꾸지 않는다. 해당 배치는 별도 간접 래스터 dispatch 1회와 중간 ColorTiles/DepthTiles 접근을 생략한다. 작업 할당·span 준비·binning은 그대로 유지한다.

Vulkan 셰이더 프로그램은 40개에서 44개로 늘었다. 추가된 4개는 텍스처 없는 일반 Z/W 변형의 비최종·최종 융합 셰이더다. OpenGL의 32개는 변하지 않았다. TileSize가 8이 아닌 구성에서는 융합 pipeline 4개를 만들지 않는다. 새 pipeline은 시작 시간·pipeline cache·바이너리 크기를 늘릴 수 있으나 이번에는 시작 시간이나 GPU 점유율을 측정하지 않았다.

## 적용 조건과 fallback

융합은 다음 조건을 모두 만족할 때만 쓴다.

- 폴리곤 1~8개, 변형 1개인 배치. 변형은 텍스처 없는 일반 Z 또는 W 셰이더다.
- TileSize 8, 1~4배율.
- 비최종 배치, 또는 Fog·AA가 없는 최종 배치. 그림자 그리기(draw)도 위 조건을 만족하면 대상이 될 수 있다.

텍스처 배치, 9개 이상의 폴리곤, 4배 초과 배율, 그림자 마스크·Toon·Highlight, Fog 또는 AA가 있는 최종 배치는 기존 경로를 그대로 쓴다.

## 검증

- 실제 AMD Radeon(TM) Graphics에서 기존 `gpu-vulkan-compute-spans`가 7.20초에 통과했다. 1·2·3배율 Z/W span 24워드와 전체 그래프 장면의 모든 픽셀을 GL 참조와 비교하고, 모든 최종 효과와 빈 마지막 배치, 두 배치의 깊이·stencil·텍스처 합성, 단일 변형 배치 순서를 확인한다. 건너뛴 항목은 없다.
- `gpu-vulkan-pipeline-cache`가 2.78초에 통과했다. 두 인스턴스가 만드는 88개 pipeline에 같은 장치 캐시를 전달하는 재사용, 동일 픽셀, 선택적 메모리 부족과 치명 오류 전파를 확인한다. 기대 pipeline 수는 고정값 대신 내장 셰이더 수에서 계산하도록 바꿨다.
- 제품 렌더러 통합 검사 `gpu-vulkan-renderer`가 5.53초에 통과했다. 1배율 native 전체 화면 비교, 257개 폴리곤 배치 계획, 3D→capture→게스트 LDRH→texture→capture, 1·2·3배율 전환을 확인한다. 건너뛴 항목은 없다.
- 변경한 9개 파일의 최종 diff는 한 번 검토해 수락했다. 창을 띄우거나 게임을 실행하지 않았다.
- 전체 회귀는 CI에서만 수행한다. Windows x64·ARM64, Ubuntu, macOS, BSD, Core regressions CI가 모두 통과했다.

## 성능 측정

제품 pipeline의 `SetFusedRaster(false/true)`로 같은 입력을 기존 경로와 융합 경로에 넣어 비교했다. 전체 높이 합성 장면 32개는 1·2·4배율, Z/W, 폴리곤 1·4·8개(4배율은 1·4개), 겹치는 폴리곤과 좁은 폴리곤 열이다. 4배율 8폴리곤은 기존 작업 용량을 넘어 제외했다. 사례마다 20쌍을 예열한 뒤 실행 순서를 번갈아 40쌍의 GPU3D 시간을 측정했고, 모든 사례에서 GL 참조와 기존 Vulkan 출력의 전체 픽셀이 일치했다. 측정용 dispatch hook은 모든 호출을 원래 함수로 넘기며 건너뛰지 않는다. 호출 수는 기존 경로에서 비어 있지 않은 배치당 래스터 dispatch 1회, 융합 경로에서 0회로 확인했다.

쌍별 중앙값은 기존 경로보다 6.77~14.97% 낮았다. 사례별로 40쌍 중 38쌍 이상에서 감소했다. 같은 경로를 양쪽에 넣은 A/A 대조의 쌍별 절대 변동 중앙값은 최대 1.60%였다. 예를 들어 2배율·Z·겹치는 8폴리곤은 중앙값 1097.4→945.4µs다.

| 배율 | 사례 수 | 감소 범위 |
| --- | ---: | ---: |
| 1x | 12 | 8.43~12.89% |
| 2x | 12 | 9.37~14.97% |
| 4x | 8 | 6.77~13.80% |

이 수치는 Radeon 내장 GPU 한 대의 합성 GPU3D 단계 시간이다. 게임 전체 FPS, 오디오·입력 지연, 시작 시간, pipeline cache·바이너리 크기, GPU 점유율, 다른 GPU는 측정하지 않았다. Vulkan이 OpenGL이나 Metal보다 항상 빠르다는 근거도 아니다. 새 외부 코드나 라이브러리는 도입하지 않았다.
