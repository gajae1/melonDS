# 1.1.232 — SDL3 출력 주기를 확인하지 못한 연결 거부

2026-09-29. SDL3·SDL2 패키지와 플랫폼 CI 검증을 완료했다. Windows x64·ARM64, Ubuntu, macOS, BSD, Core regressions CI가 모두 통과했다.

## 변경

SDL3 출력 스트림을 연 뒤 논리 장치가 없거나, 장치 정보 조회가 실패하거나, 버퍼 주기가 0 이하이면 연결 실패와 구체적인 오류를 반환한다. 이전에는 요청한 버퍼 크기를 실제 적용값으로 대신 기록했다. 이제 유효한 장치 주기를 확인한 경우에만 연결을 성공으로 처리하며, 실패한 스트림은 기존 소유 스레드에서 정리한다.

정상 SDL3 연결과 SDL2·WASAPI 출력 경로는 바꾸지 않았다. 새 외부 코드나 라이브러리는 도입하지 않았다.

## 검증

실제 SDL3 더미 장치에 세 가지 조회 실패를 주입한 검사에서 기존 코드는 실패하고 수정안은 통과했다. 오류 전달, 전역 버퍼 힌트 복원, 실패한 스트림의 1회 해제와 이후 정상 재열기를 확인했다. 기존 첫 콜백의 추가 할당 없음 검사도 통과했다.

장치 재생과 게임플레이는 수행하지 않았다. WASAPI에서 시간이 지날수록 커지는 틱 노이즈의 원인은 재현하지 않았고, 물리 오디오 지연이나 속도 개선을 주장하지 않는다. 전체 회귀 검사는 플랫폼 CI에서 수행한다.
