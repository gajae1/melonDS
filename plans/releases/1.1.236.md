# 1.1.236 — SDL3 게임패드 중복 갱신 제거

2026-09-29. 소스 커밋: `f56aae73e0b0e138a8c565f6a34229932b50bd71`.
SDL3·SDL2 패키지와 플랫폼 CI 검증을 완료했다.

1.1.236은 SDL3에서 연결된 게임패드의 평상시 입력 갱신을 프레임당 두 번에서 한 번으로 줄인다. SDL_UpdateGamepads가 내부적으로 SDL_UpdateJoysticks를 다시 호출한다는 SDL 구현에 근거한다. 장치 목록 변경이나 재연결 후 센서 활성화에 필요한 추가 갱신은 유지한다. 물리 입력 지연·게임 FPS는 측정하지 않았다.

## 변경과 검증 범위

- 입력 처리는 기존 SDL_UpdateJoysticks를 유지한다. 연결 목록이나 재시도 조건으로 openJoystick을 호출했을 때만 SDL_UpdateGamepads를 추가 호출한다.
- [SDL 3.4.16 원문](https://github.com/libsdl-org/SDL/blob/release-3.4.16/src/joystick/SDL_gamepad.c#L3176)의 두 API는 같은 전역 갱신을 실행한다. 새 센서 활성화가 앞선 갱신보다 늦는 경우에는 추가 갱신이 필요하다.
- 실제 입력·열기·닫기·버튼 함수를 추출한 SDL3 가상 게임패드 검사에서 기준 버전은 갱신 2회로 실패하고 후보는 1회로 통과했다. 버튼·축·핫키와 가상 센서의 최초·연속·재연결 갱신을 확인했다. 일련번호 없는 재연결은 기존처럼 명시적 선택을 요구한다.
- SDL2 기존 가상 조이스틱 회귀 검사 12개가 통과했다. 전체 회귀 검사는 CI에서만 실행한다.
- Windows x64·ARM64, Ubuntu, macOS, BSD, Core regressions CI가 모두 통과했다.

게임 플레이·물리 컨트롤러·입력 지연 계측은 하지 않았다. 호출 횟수 감소를 FPS나 밀리초 지연 개선으로 환산하지 않는다. 오디오 틱 노이즈·JIT·그래픽 변경은 없다.

오디오 출력 경로의 추가 읽기 검토에서는 새 결함이 입증되지 않았다. 앞서 검토한 로우패스 계수 캐시 후보는 SSE2·스칼라 성능 악화로 반영하지 않았다.
