# 1.1.187 — Vulkan native 2D 기반(기본 비활성)

2026-09-27. 릴리스 소스 커밋은 `4384ec01e6db28a5c80065821668cad5b62ad1d8`이며 구현 커밋은 `b47663c8`이다. SDL3·SDL2 패키지와 플랫폼 CI 검증을 완료했다.

## 변경

2D 픽셀 처리를 GPU로 옮기는 native 2D 기반을 추가했다. 활성화 진입점 `VulkanRenderer::InitNative2D()`를 호출하는 생산 경로가 없으므로 기본 렌더러 선택과 사용자 동작은 1.1.186과 같다.

- native 경로: 명령 큐·상태·메모리·기록(`Native2DQueue/State/Memory/Record`), `Native2DPipeline`, `Native2DCapture`, `Native2DFinal`과 셰이더(`Native2D.comp`, `Native2DMerge.comp`, `Native2DCapture.comp`, `Native2DCaptureHires.comp`, `Native2DFinal.glsl`, `Native2D/*.glsl`). 코드와 SPIR-V는 기본 바이너리에 포함되지만 실행되지 않는다.
- 텍스처·캡처: GPU 소유 구간에서만 쓰는 텍스처 디코드(`TextureDecode`)와 캐시 분리(`TextureCache.cpp`), native 3D 이미지 보존(기본 off).
- 기본 경로 변경: `GPU::MapVRAM_CD`가 C/D 뱅크를 ARM7로 넘기기 전에 이전 매핑 상태에서 캡처 블록을 동기화·무효화한다. `InvalidateDisplayCapture`는 블록 수를 함께 받는다. `GPU3D_Texcache.h`의 native 훅은 훅이 있는 로더에만 적용되어 OpenGL과 소프트웨어 경로는 기존 CPU 텍스처 경로를 쓴다.
