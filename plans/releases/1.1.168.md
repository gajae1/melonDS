# 1.1.168 — SDL3 출력 주기·게임패드 폴링 보정

2026-09-24. 이전 버전 1.1.167. 기본 배포 설정은 SDL2이며 SDL3는 `ENABLE_SDL3=ON` 선택형 빌드다.

SDL3 출력 장치를 열기 전에 읽은 선호 버퍼 주기를 실제 콜백 주기로 표시하던 오류를 고쳤다. Windows WASAPI에서 128프레임을 요청한 재현 사례는 열린 장치와 콜백이 480프레임인데 UI 상태에는 128프레임을 보고했다. 열린 logical device에서 다시 조회한 뒤 480프레임을 보고하고, 열기·중지·재개·비동기 재열기·닫기 probe가 통과했다. SDL3 게임패드 상태를 수동 갱신하는 경로에서는 사용하지 않는 joystick/gamepad 이벤트 생성을 꺼서, 가상 패드 버튼 100회 전환 때 대기 이벤트 198개가 0개로 줄었다. 버튼 상태와 연결·분리 폴링은 유지됐다.

선택형 SDL3 Qt 전체 빌드를 Windows의 제한된 PATH에서 실행해 ROM 사본 부팅, 살아 있는 창과 정상 종료를 확인했다. SDL3 DLL·라이선스를 포함하고 SDL2 DLL을 제외한 배포 디렉터리에서도 재실행했다. SDL3 disk backend의 제품 출력 probe는 알려진 PCM을 기록했고, 30초 격리 게임 실행은 약 13.18초부터 0이 아닌 게임 PCM을 기록했다. 이는 실제 스피커 청감·지연, 물리 패드, 마이크 캡처, 장치 분리·재연결, 가시 화면 및 장기 사용 수락과 구분한다. 가상 마이크 dummy callback 수명은 별도 sidecar에서만 확인했다. 원시 probe와 로그는 로컬 비공개 `local-docs/bv20-sdl3-runtime-20260924/`, `local-docs/bv20-gamepad-probe-20260924/`, `local-docs/bv20-sdl3-mic-20260924/`에 있다.

ARM9 JIT 저장 후 캐시 재설정의 숨은 CPU·타이머 상태 차이는 [1.1.167](1.1.167.md)의 미해결 사항으로 남는다. 두 정산 시제품은 실게임 상태 또는 기존 출력이 달라 제품에 포함하지 않았다.

커밋 `bcc22c87`의 깨끗한 소스 복제본 `build/1.1.168-source`에서 기본 SDL2와 선택형 SDL3 Windows UCRT64 Release 빌드가 각각 exit 0이었다. 기본 SDL2 전체 CTest는 **1,023/1,023**, SDL3 오디오·입력 집중 CTest는 **48/48** 통과했다. SDL3 테스트의 첫 대소문자 필터는 0개를 선택했으므로 통과 근거에 넣지 않고 정확한 등록 이름으로 다시 실행했다. 두 실행 파일의 패키지 소스 식별자는 `1bb98066b80dbdc250d17c8991aa0f1008a4d57dc42f862ba1c757cae406828d`이며, 소스 커밋을 검증한 packager가 동일성을 승인했다. 기존 작업 중인 teakra 파일은 복제·빌드·패키징에서 제외했다.

SDL2 기본·SDL3 선택형 배포와 패키징은 각각 exit 0이었고, 각 런타임 ZIP은 325개 파일과 개인 파일 0개를 담는다. SDL2 ZIP에는 `SDL2.dll`만, SDL3 ZIP에는 `SDL3.dll`만 들어 있다. 패키징은 제한된 PATH의 `--help`·`--build-info`, 배포 manifest의 파일 해시, ZIP의 항목별 해시와 소스 ZIP을 확인했다. SDL3 ZIP을 새 디렉터리에 풀고 격리 ROM 사본을 20초 부팅한 뒤 숨긴 Qt 창 `[60/60]`과 `WM_CLOSE` exit 0, 0이 아닌 디스크 PCM, 원본 ROM 해시 보존을 재확인했다. 이 검사는 실제 스피커 청감이나 보이는 UI를 수락하지 않는다. Qt 번역 catalog와 선택적 D3D12 구성요소 부재 경고가 남아 해당 동작도 수락하지 않는다.

이 해시 표는 패키징 이후 추가한 문서 기록이므로 소스 ZIP 안의 같은 문서에는 들어 있지 않다. 실행 코드·소스 식별자는 바뀌지 않았다.

후속 FS-07 실제 archive 진입 점검에서는 위 기본 SDL2 ZIP을 각각 새 격리 디렉터리에 풀고, 원본 해시가 같은 64MiB 사설 ROM의 한글 이름 멤버를 ZIP·TAR·7z로 만들었다. 세 형식 모두 `archive|member` 인수로 실행해 카트 코드 `VCDJ`·게임 부팅 로그, 두 시점의 살아 있는 `[60/60]` Qt 창, `WM_CLOSE` exit 0, 원본 ROM 해시 보존을 확인했다. 오디오는 dummy였고 창은 숨겨져 있었다. 7z 스모크 하네스의 원시 판정은 SDL2 로그 문구를 `SDL2 / dummy`로 잘못 예상해 `fail`이지만, 실제 로그는 `SDL / dummy`이며 부팅·창·종료·해시 필드는 모두 충족했다. 원시 결과를 보존하고 로그를 직접 대조했으며 실행을 반복하지 않았다. 이 세 입력의 게임 진입을 전체 archive 형식·다른 게임·보이는 화면·청감 수락으로 확대하지 않는다. 비공개 기록은 `local-docs/fs07-zip-20260924/`, `local-docs/fs07-tar-20260924/`, `local-docs/fs07-7z-20260924/`에 있다.
