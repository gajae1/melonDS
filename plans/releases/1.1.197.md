# 1.1.197 — 스테레오 계수 공유와 x64 ALU 복사 감소

2026-09-28. 릴리스 소스 커밋은 56eff39d16e216401ec5b9d6cd71d43ca7aaf7b6다. SDL3·SDL2 패키지와 플랫폼 CI 검증을 완료했다.

## 구현

MinimumPhase의 dense 이력에서 좌우 채널을 따로 계산하며 같은 계수를 두 번 읽던 부분을 묶었다. AVX2/FMA와 NEON은 계수를 한 번 읽고 두 누적기에 적용한다. 각 채널의 FMA·합산 순서는 기존과 같고, 가운데 패닝은 기존 단일 Dot을 유지한다. 런타임 CPU/OS 검출과 강제 스칼라 설정을 보존하므로 AVX2를 새 필수 요구사항으로 만들지 않는다. 계수·고음 응답·필터 길이·이벤트 시각·게인·패닝은 변경하지 않았다.

x64 JIT는 목적지와 첫 피연산자가 다른 산술에서 불필요한 임시 레지스터 왕복을 줄인다. 플래그가 필요 없는 ADD와 즉시값 SUB는 LEA, 상수 PC 상대 연산은 MOV로 접는다. 그 외에는 피연산자 별칭이 허용할 때 목적지에 직접 계산한다. 살아 있는 플래그와 carry 입력, shifter carry, 게스트 PC·사이클 경로는 유지한다. ARM64 JIT 변경은 없다.

## 근거와 한계

- GCC 16 x64 생성 코드에서 스테레오 계수 벡터 읽기는 8회에서 4회로 줄고 두 SIMD 호출은 하나로 합쳐진다. JIT의 해당 3명령 연산은 LEA 1개 또는 직접 계산 1~2개가 된다. 이것은 작업량 감소이며 전체 게임 FPS 향상률이 아니다.
- 독립 프로세스 오디오 커널 5쌍 측정에서는 dense stream512 중앙값 −15.94%, renderer512 −11.27%, renderer352 −11.75%가 나왔다. 그러나 같은 baseline A/A도 최대 약 19% 변동했다. 동일 프로세스 비교에서도 중앙 패닝 대조군에 큰 차이가 있었고 두 변이의 인라인 경계가 다름을 확인해 DotStereo 효과만 분리할 수 없었다. 따라서 **시간 개선률은 채택하지 않는다**. 원시·부정 결과를 함께 보존했다.
- 기존 차등 harness의 자동 SIMD와 강제 스칼라 각각 669,259개 기록(4,406,620바이트)이 이전 코드와 전부 일치했다. 실제 계수·스트림·renderer를 쓰되 SPUChannel 필드 어댑터를 사용한 커널/수집 검사다.
- 기존 MinimumPhase, SIMD 켜기/끄기, 강제 스칼라 및 interpreter/JIT/fastmem ALU·device 관련 12개 검사가 통과했다. ALU 검사는 목적지 별칭, 시프트/즉시값, live/dead flags, PC, BVS와 원본 레지스터 보존을 확인한다.
- Black·Solatorobo 각 1200프레임, built-in DS·software renderer·기본 fastmem·MinimumPhase 모드5에서 이전 1.1.196과 누적 framebuffer digest, 최종 PPM, 누적 PCM이 일치했다. 플레이·데스크톱 조작 없이 실행했다. 실제 저사양 기기 청취나 장기 재생을 대신하지 않는다.
- Windows x64·ARM64, Ubuntu, macOS, BSD, Core regressions CI가 모두 통과했다.
