# 1.1.191 — Vulkan 화면 합성 대기를 VBlank와 겹치기

2026-09-27. 릴리스 소스 커밋은 `bce13e0b7a395a7278f304d26215eaa08a7b65bd`이며 구현 커밋은 `b5d53252`이다. SDL3·SDL2 패키지와 플랫폼 CI 검증을 완료했다.

## 변경

확대 배율(2배율 이상)의 Vulkan 렌더러는 한 프레임의 화면 줄을 GPU에서 합성한 뒤 CPU가 그 완료를 바로 기다렸다. AMD 내장 GPU 4배율에서는 이 대기가 프레임당 약 2.5ms였다.

- 합성을 VBlank(192줄)에서 제출만 하고, 결과를 처음 쓰는 시점에 완료한다. VCount 215의 다음 3D 렌더, VCount 조작으로 재개된 화면 줄, 프레임버퍼 읽기·세이브스테이트, Qt 표시 스레드 전달(`GetResidentFrame`), 배율 변경, 종료가 여기에 해당한다. 1.1.189의 `Device::SetPendingCompletion`으로 같은 장치의 다른 사용자도 먼저 완료한다.
- 제출 중에는 입력 3D 이미지와 CPU 복사 대상 행을 보존하고, 완료 실패 시 기존 CPU 재구성 폴백을 그대로 쓴다.
- 직접 표시 경로의 동기화: 표시 스레드는 `renderLock`을 잡은 채 `GetResidentFrame`과 `Present`를 호출하므로 큐 접근이 직렬화되고, 전달 전에 합성이 완료된다. 같은 큐의 표시 명령은 기존 이미지 barrier로 합성 결과를 읽는다.
