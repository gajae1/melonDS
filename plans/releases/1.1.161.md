# 1.1.161 — 출력 보존을 확인한 다섯 영역의 반복 작업 감소

2026-09-22. 기준 1.1.160 `f41a9878`, Windows UCRT64 Release.

## 채택 범위

- 압축 텍스처는 4×4 블록의 네 색상을 출력 형식으로 한 번씩 변환하고 재사용한다.
- x64 Thumb의 레지스터 시프트는 기존 flag liveness가 carry 출력을 쓰지 않는다고
  판정한 경우에만 carry 생성 명령을 생략한다. ADC/SBC/RRX의 carry 입력은 유지한다.
- 휴면 scheduler의 다음 deadline 조회는 기존 네 종류의 허용 이벤트만 추린 뒤
  활성 비트를 ID 순서로 순회한다. 깨어 있는 scheduler는 기존 구현을 유지한다.
- Teakra BTDMP 두 인스턴스의 비어 있는 Tick/Skip/GetMaxSkip callback 등록을 제거한다.
  실제 I2S SampleClock·FIFO·timer·IRQ 처리는 그대로다.
- Software 3D는 Z-buffer에서 깊이 검사로 탈락한 픽셀과 shadow mask의 불필요한
  원근 계산을 생략한다. W-buffer에서는 깊이에 필요한 원근 계산을 먼저 수행한다.

렌더링 배율·정밀도, 필터 계수·음질 설정, 기본 버퍼와 guest timing은 바꾸지 않는다.

## 집중 검증과 측정

아래 수치는 이 PC에서 실제 제품 함수를 실행한 제한된 부하의 시간 감소다.
게임 FPS 향상률이나 모든 workload의 회귀 없음으로 해석하지 않는다.
각 영역은 출력·상태 또는 실제 실행 작업량을 함께 대조했고, 측정은 직렬로 수행했다.

| 영역 | 채택 근거 | 측정 결과 |
|---|---|---|
| 압축 texture | 648 decode 사례·세 출력 형식·wrap·투명도·실제 cache miss/hit의 61,780,472바이트 일치 | 같은 프로세스에서 직접 decode 약 55~63% 감소, 큰 cache miss 55.67% 감소, 작은 miss 2.42% 감소 |
| Thumb register shift | 두 CPU의 interpreter/native register·CPSR·cycle 3,040건 일치, 기존 ALU 3,056건 통과 | carry 출력이 죽은 블록 18~20바이트 감소, 해당 dispatch 중앙값 약 4.4~9.7% 감소 |
| 휴면 deadline | 전체 27개 slot의 deadline, callback mutation 6건·scheduler savestate 9건 통과 | 여섯 mask에서 약 35~94% 감소 |
| DSP callbacks | 실제 LLE의 timer·IRQ/ISR·I2S·PCM·저장 후 재개 277,100바이트 일치 | active tick 약 19.1%, timer pause 20.7%, idle skip 18.9% 감소 |
| Software 3D | 9개 장면×4변형의 두 layer color/depth/attribute·scanline·stencil 일치, 단일/별도 render thread 대조 | Z overdraw 12.7%, Z AA 6.6%, Z shadow 3.0% 감소 |

Software 3D는 계측 빌드에서 픽셀 방문·탈락·하위 AA layer 수락·polygon별 stencil
trace도 대조했다. 대표 Z overdraw의 X 방향 나눗셈은 571,675→49,152회,
Z shadow는 514,984→236,615회이며 W 나눗셈 수는 동일했다.
계측하지 않은 별도 빌드에서 순서를 교대한 4쌍×4프레임으로 시간을 측정했다.
Z visible 중앙값은 3.8%, equal-W Z는 15.5% 감소했으나 나눗셈 감소만의 효과로
귀속하지 않는다. W visible은 2.2%, W shadow는 1.0% 늘었다.

변경하지 않은 대조 경로에서도 변동이 있었다. texture의 indexed/warm 중앙값은
-3.69~+0.65%, scheduler의 awake 대조는 -6.19~+5.42%, JIT의 동일 크기 live-carry
블록은 -5.49~+5.26%였다. DSP active의 5쌍 중 한 쌍은 15.3% 느렸으며
sample-clock-only 중앙값은 0.95% 감소했다. 전체 원시 결과를 보존했다.

## 제외한 후보

- Dense audio mixer-grid indexing은 PCM·상태 일치를 통과했으나 실제 SPU 부하에서
  일관된 이득이 없어 원본으로 복원했다.
- Awake scheduler의 비트 순회는 일반 DS 조합에서 13.72% 느려 원본으로 복원했다.
- Thumb 즉시값 시프트의 carry 생략은 ARM9 대조에서 약 2% 느려 제외했다.
  레지스터 시프트만 남긴 최종 후보에서 해당 native/interpreter·기존 ALU 검사를 통과했다.

원본 로그·측정 파일은 `local-docs/optimization-161-20260922/`에 보관했다.

## 통합 검증과 패키지

검증 소스 `cb73996e`의 독립 Release 빌드가 exit 0으로 끝났고, 전체 CTest
**1016/1016**이 통과했다. 실패·건너뜀·비활성 0, 225.56초다.
기존 미완성 `test_generator.cpp` 수정은 커밋과 배포 빌드에서 제외하고 보존했다.

Solatorobo와 Pokémon Black을 OpenGL 1배·8배 및 software 1배에서 각각
1200프레임, 이전/신규/신규/이전 순서로 실행했다. 모든 대조에서 최종 전체
BGRA 화면(1x 393,216바이트, 8x 25,165,824바이트), native PPM과 누적 PCM
