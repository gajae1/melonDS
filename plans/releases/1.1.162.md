# 1.1.162 — text BG·저장 게시 비용 감소와 카메라 입력 정확성

2026-09-23. 제품 변경 기준 `ee911514` (이전 1.1.161 `1d7d4c71`). Windows UCRT64 Release.

## 변경

- Software 2D의 비모자이크 text BG는 화면에서 보이는 타일 구간마다 타일 정보·팔레트·행 주소·반전 방향을 준비한다. 픽셀별 창·투명도·VRAM 마스크·합성 순서는 유지한다. 모자이크 경로는 그대로다.
- SaveManager는 새 크기·복구·감김·빈 쓰기를 제외하고, 게시 전 변경된 구간의 보수적 합집합만 보조 버퍼로 복사한다. 디스크 쓰기용 전체 스냅샷과 `QSaveFile` 교체·실패 재시도 계약은 그대로다.
- Qt 카메라 입력은 각 plane의 `bytesPerLine`을 사용한다. 정지 이미지는 RGB32 변환 결과의 픽셀을 읽고, 재초기화 중 실행 중이던 카메라의 시작 요청을 보존한다.

## 범위와 측정

두 엔진의 text BG 6,144개 고정 장면에서 기존·신규의 전체 layer/합성 출력 18,874,372바이트가 일치했다. 4bpp·8bpp·확장 팔레트, 타일 양방향 반전, 화면 크기·스크롤 감김, 창·모자이크를 포함한다. 국소 5,000행 반복 측정의 대상 경로는 엔진별 중앙값 약 9.8~13.1% 빨랐다. 모자이크와 완전 가림 대조 경로는 약 -2.3~+4.3% 범위였다. 원본·후보 출력과 원시 측정값은 `local-docs/optimization-162-20260923/text-bg/`에 보존했다. 이 수치는 게임 FPS가 아니다.

SaveManager의 4개 실제 파일 검증·재시도·복구·동시 사례가 기존과 바이트 단위로 일치했고, 후보 소스의 기존 선택 검사 17건이 통과했다. 1MiB save에서 64바이트 부분 쓰기 2,048회 게시의 3회 측정은 기존 29.11~29.96ms, 신규 0.069~0.081ms였다. 전체 쓰기 대조는 기존 75.13~76.94ms, 신규 75.89~77.87ms였다. 원시 결과는 `local-docs/optimization-162-20260923/save-manager/`에 있다. 실제 게임의 저장 빈도·물리 디스크 지연으로 일반화하지 않는다.

생성된 패딩 YUYV/UYVY/NV12/RGB 입력, 인덱스 이미지, 시작 후 재초기화에서 카메라 집중 검사를 통과했다. 이 환경의 Qt 이미지 로더는 RGB888로 저장한 PNG/JPEG를 RGB32로 읽어 RGB888 파일 fixture를 재현할 수 없었다. 실제 카메라 분리·재연결과 장시간 촬영은 검증 범위 밖이다.

## 통합 검증과 배포

독립 소스 `build/1.1.162-source`의 Release 빌드는 exit 0, 전체 CTest는 **1,022/1,022** 통과했다(247.88초). 실패·건너뜀 없이 새 카메라·저장·text BG 검사도 포함한다. 기존 작업 중이던 `src/teakra/src/test_generator.cpp`는 이 버전의 소스·빌드·커밋에서 제외하고 보존했다.

Solatorobo와 Pokémon Black을 software 1배 및 OpenGL 1배에서 각각 1,200프레임, 이전/신규/신규/이전 순서로 실행했다(총 16회). 네 조합 모두 최종 전체 BGRA 393,216바이트, native PPM 294,927바이트, 누적 PCM 3,851,152바이트가 저장 파일 원본의 직접 비교에서 일치했다. 실행시간은 software Solatorobo 평균 2.5395→2.5120초, Black 1.7145→1.6650초, OpenGL Solatorobo 1.3790→1.3890초, Black 1.6990→1.6665초였다. 짧은 두 번의 실행으로 일반 게임 FPS 개선·회귀 없음을 단정하지 않는다. 최종 프레임 대조는 모든 중간 프레임·Qt 창 표시·카메라 장치 입력을 검증하지 않는다. 원본 파일과 측정 기록은 `local-docs/optimization-162-20260923/`에 보존했다.

Windows 런타임·소스 ZIP 검증은 진행 중이다. 실제 카메라 탈착, 저장의 전원 손실 내구성, 장시간 청취·Qt 표시, 다른 CPU/드라이버는 별도 수락 범위다.
