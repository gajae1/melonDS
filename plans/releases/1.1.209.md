# 1.1.209 — ARM64 Thumb 레지스터 시프트·소프트웨어 3D 포그 색상 패킹

2026-09-29. SDL3·SDL2 패키지와 플랫폼 CI 검증을 완료했다.

## 변경

- ARM64 Thumb 레지스터 시프트: LSL/LSR/ASR/ROR의 결과를 mapped Rd에 직접 계산한다. 공통 emitter의 `Comp_RegShiftReg`는 선택적 결과 레지스터를 받고 기본 W0를 쓰므로 ARM 호출자는 그대로다. count를 W1로 먼저 추출해 목적지를 바꾸기 전에 보존하므로 Rs=Rd 별칭을 처리하고 플래그 의미를 유지한다. carry를 쓰는 경로에서 복사 2개, 쓰지 않는 경로에서 1개를 제거한다.
- 소프트웨어 3D 최종 패스 포그: 포그 색상의 R/B와 G/A를 u32의 16비트 lane 두 개에 함께 적재해 가중 합을 한 번에 계산한다. 가중 합은 최대 63×128=8064, 알파는 최대 31×128=3968이라 lane 올림이 없다. 알파 전용 경로는 스칼라로 유지하고 미사용 비트를 마스킹한다. 상·하단 포그, 에지 마킹, AA 순서는 바꾸지 않는다.

## 작업량과 한계

| 조건 | 1.1.208 | 1.1.209 |
| --- | ---: | ---: |
| ARM64 Thumb 레지스터 시프트의 중간 결과 복사 | carry 사용 2개·미사용 1개 | 0개 |
| GCC16 x64 -O3 FinalPass·CalculateFogDensity 전체 함수의 static `imul` 사이트 | 41개 | 33개 |

ARM64 실행 의미 검증에는 기존 1.1.208의 CoreALUExecution Thumb 시프트 검사를 재사용한다. `imul` 사이트 수는 전체 함수의 정적 명령 수이고 wall-clock·FPS가 아니다. 표시 캡처 패킹과 알파 계수 후보는 컴파일러가 좁은 `pmullw`를 더 많은 `pmuludq`로 바꿔 채택하지 않았고 출하하지 않는다. SDL·백엔드 기본값은 바꾸지 않았다.

## 검증

- 로컬 집중 검사 3개가 통과했다: 소프트웨어 셰이딩, 소프트웨어 캡처, ARM64 산술 인코딩. native ARM64 실행은 CI에서 수행한다.
- 이전/새 프로덕션 FinalPass·CalculateFogDensity 전체 함수를 3,120 case, 상·하단 합계 1,597,440픽셀에서 완전한 색·깊이·속성 배열로 대조해 일치했다. 밀도 0–128·끝점·램프, 색상·알파 전용 포그, AA, 에지 플래그와 shift 0–15를 포함한다.
- ARM64 Thumb 레지스터 시프트는 기존 1.1.208 CoreALUExecution Thumb 시프트 검사(레지스터 별칭·carry·0/32·부분 flags·guest 사이클)를 재사용한다. 네이티브 ARM64 CI에서도 실행하는 검사다.
- Windows x64·ARM64, Ubuntu, macOS, BSD, Core regressions CI가 모두 통과했다.
