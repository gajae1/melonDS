# 1.1.230 — Vulkan native 2D 연속 업로드 복사 생략

2026-09-29. SDL3·SDL2 패키지와 플랫폼 CI 검증을 완료했다.

## 변경

Native2DPipeline.cpp가 기존 lease 순회 안에서 모든 MemoryCopy 목적지가 연속인지 함께 확인한다. 플래너 할당이나 정렬은 추가하지 않았다. 연속이고 교차한 새 꼬리 구간이 8192바이트 이상이며, 실제 host target 메모리에 HOST_CACHED가 없고 소스 중 현재·확장 전 arena 메모리가 없을 때만 그 구간의 CPU memcpy와 staged vkCmdCopyBuffer를 모두 생략한다. 앞부분 GPU 보존·확장, 소스 복사 순서, fence, 병합 기록 꼬리는 그대로다. 작거나 조각난 경우, 순서가 바뀐 경우, HOST_CACHED, 전체 self-copy는 기존 순차 경로를 쓴다. 새 외부 코드와 GL·JIT·오디오 변경은 없다.

## 검증

- 실제 Radeon native-copy tier0 flags7과 강제 tier1 flags6이 픽셀·간격·임계값·보존·증가·병합 검사와 실제 stage copy 영역·meter 검사를 통과했다.
- 기존 gpu-vulkan-native-deferred 테스트(기본 GPU)가 3.68초에 통과했다.
- 게임플레이와 전체 로컬 테스트는 수행하지 않았다. 전체 회귀는 CI에서만 수행한다.
- Windows x64·ARM64, Ubuntu, macOS, BSD, Core regressions CI가 모두 통과했다.

## 측정

범위는 실제 Radeon mapped memory에 대한 합성 CPU 준비(연속 CPU mapped 저장 + 분리한 적격성 검사)뿐이다. GPU 실행·전체 파이프라인 제출·게임 FPS·물리 오디오·입력 지연은 측정하지 않았다. 4 A/B 쌍·4 A/A 쌍 중앙값이다(비공개 mapped-summary.json).

| 조건 | 변화 | A/A |
| --- | --- | --- |
| 16KiB 연속 | -24.87% | 0.77% |
| 64KiB 연속 | -39.36% | 2.10% |
| 16KiB 조각남 | +5.31% | 5.30% |

조각난 16KiB는 A/A 경계에 걸리는 애매한 결과이며 악화 가능성을 배제하지 않는다. 그 밖의 fallback 조건은 A/A 안이다. 경계 측정에서 16·64KiB의 256~4096바이트 구간은 나빠지고 8192바이트부터 좋아져 임계값 근거가 되었다. 캐시된 host 대상의 이전 탐침은 나빠져 보수적으로 fallback한다. 일반 union 후보는 조각난 경우 10.8배 악화로 기각했다.

## 남은 범위

게임플레이 FPS, GPU 실행 시간, 전체 제출 시간, 다른 GPU·드라이버는 확인하지 않았다. 기존 Vulkan 저수준·JIT·오디오 로드맵은 열려 있으며 이 버전은 원래 과제의 전체 완료를 뜻하지 않는다.
