# 1.1.203 — Vulkan 타일 임시 저장소 감소

2026-09-29. 릴리스 소스 커밋은 `02b1a6e035cd1a5620a2bbec9ab94a6b5e2f7156`다. SDL3·SDL2 패키지와 플랫폼 CI 검증을 완료했다.

## 변경

Vulkan raster 단계의 색상·깊이·속성 세 타일 버퍼 중 속성 버퍼를 제거한다. 경계와 커버리지 속성은 불투명 픽셀에서만 소비하므로, 그 픽셀의 알파 바이트를 재사용한다. 좌/우 경계는 배타적이고 위/아래 경계도 배타적이며 커버리지는 5비트다. 195개 유효 조합을 태그 31~33과 64~255로 표현하고, 깊이 검사를 통과한 불투명 픽셀을 합성하기 전에 원래 알파 31과 속성을 복원한다.

반투명 알파 1~30과 RGB 하위 24비트, 깊이 32비트는 유지한다. 그림자 마스크는 태그가 아닌 원래 polygon 속성으로 구분한다. 일반 불투명 픽셀에도 태그 255가 가능하기 때문이다. 알파 탈락·미피복 픽셀은 계속 0을 기록한다. GL 참조 경로와 배치 간 결과 7워드, 버퍼 재사용 장벽·배치 분할 한도는 바꾸지 않았다. 기존 descriptor 번호를 유지하기 위해 사용하지 않는 속성 버퍼 슬롯만 4바이트로 남긴다.

## 절감 범위

일반 알파 통과 fragment의 중간 저장은 12→8바이트이며, 불투명 합성에서 속성을 읽던 4바이트도 제거된다. 캐시와 컴파일러에 따라 실제 메모리 트래픽은 달라진다. 패킹·복원의 정수 연산은 추가된다.

아래는 기존 자원 제한 검사의 동일 한도에서 계산한 **버퍼 범위**다. GPU 전체 메모리나 드라이버 heap 사용량, 게임 FPS 측정값이 아니다.

| 배율 | 이전 타일 임시 버퍼 | 변경 후 | 감소 |
| --- | ---: | ---: | ---: |
| 1배율 | 9,437,184 B | 6,291,460 B | 약 3MiB |
| 4배율 | 50,330,880 B | 33,553,924 B | 약 16MiB |

PC에서 다른 프로그램을 사용 중인 환경이므로 실행 시간으로 채택 여부를 판단하지 않았다. 이번 버전의 근거는 임시 저장소·접근 감소와 출력 보존이며, 속도 향상이나 모든 구형 GPU의 이득을 주장하지 않는다.

## 검증

- `vulkan-resource-limits`: 기존 1~16배율의 허용·거절·제한 장치 검사가 통과했다. 표시되는 scratch 합계를 실제 세 슬롯 크기의 합으로 수정했다.
- `gpu-vulkan-compute-spans`: Radeon에서 GL/Vulkan의 1·2·3배율 Z/W 전체 픽셀이 일치했다. 기존 텍스처·그림자 split과 함께 알파 30/31/탈락, 검정·최댓값 색상, 한 줄 높이의 경계 장면을 추가했다. 같은 scratch에 알파 1을 먼저 기록한 뒤 탈락시켜 이전 픽셀 누출을 확인하며, 실제 불투명·반투명·탈락 픽셀이 존재해야 통과한다. 1배율에서는 모든 최종 효과 조합과 빈 마지막 배치도 대조했다.
- `gpu-vulkan-capture-texture-3x`: native 캡처와 확대 표시·재사용 경로 검사가 통과했다.
- 생성된 4배율 SPIR-V의 raster/blend 변형 26개에서 속성 storage binding이 사라진 것을 확인했다.
- Windows x64·ARM64, Ubuntu, macOS, BSD, Core regressions CI가 모두 통과했다. 전체 검사는 CI에서만 실행한다.
