# 1.1.202 — x64 역뺄셈 결과 복사 감소

2026-09-29. 릴리스 소스 커밋은 `ce414b65cdaf9fea1fea67788122c0eeaed76d1f`다. SDL3·SDL2 패키지와 플랫폼 CI 검증을 완료했다.

## 변경

x64 JIT의 ARM RSB·RSC는 Operand2에서 Rn을 빼거나 carry를 반영해 뺀다. 이전에는 Operand2를 임시 레지스터로 옮겨 계산하고 결과를 목적지로 복사했다. 이제 목적지가 Rn과 다르면 목적지에서 직접 계산한다. 목적지가 Rn과 같으면 원래 Rn이 덮이지 않도록 기존 임시 레지스터 경로를 유지한다. carry 입력 준비, 플래그 회수와 guest 사이클 처리는 바꾸지 않았다.

시프트 없는 Operand2의 계산부는 독립 목적지에서 MOV·SUB/SBB·MOV 3명령이 MOV·SUB/SBB 2명령으로 줄고, 목적지가 Operand2와 같으면서 Rn과 다르면 SUB/SBB 1명령이 된다. 목적지가 Rn과 겹치면 기존 명령 수를 유지한다. 이미 시프트 결과가 임시 레지스터에 있는 경로도 명령 수가 같다. 기존 RSB #0의 NEG 경로는 그대로다. 실제 게임 FPS나 구형 CPU의 향상률은 측정하지 않았다.

## 검증

- 기존 `core-jit-alu-shift`, `core-fastmem-alu-shift`가 각각 6,948개 결과·플래그 대조를 통과했다. ARM7·ARM9의 캐시된 JIT 실행, 목적지 중첩, register·shifted·immediate Operand2, live·부분 dead·전체 dead 플래그와 carry 경계값을 포함한다. 기대값은 독립된 64비트 산술로 계산한다.
- ADPCM 크기표는 1.1.174에서 실제 16채널 제품 부하가 느려져 기각된 기록을 확인하고 재구현하지 않았다. 오디오 계수·음질·기본값 변경은 없다.
- Windows x64·ARM64, Ubuntu, macOS, BSD, Core regressions CI가 모두 통과했다. 전체 검사는 CI에서만 실행한다.
