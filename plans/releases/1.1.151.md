# 1.1.151 — cached full-readback landing의 중복 host memcpy 제거

2026-09-20. 기준 1.1.150 HEAD 7da51221. 메인 checkout과 빌드는 F:/melonDS, build/windows-dev다.

## 구현 — 조건부 copy 생략

full-readback 체인은 합성 이미지를 renderer 소유 host-visible `readback` buffer에 내린 뒤 무조건 `hostReadback` vector로 memcpy했다(16x ~2.0ms, 48MiB). 런타임 probe가 이 buffer의 실제 memory flags가 0x0e(HOST_VISIBLE|HOST_COHERENT|**HOST_CACHED**)임을 확인했다 — cached landing에서는 copy가 중복 cached→cached pass다.

`ComputePipeline::FullReadbackPixels()`가 cached이면 mapped `readback` span을 직접 반환하고, uncached fallback이면 기존 memcpy+vector를 유지한다. RenderView·ReadbackView 둘 다 사용. fullReadbackValid·consume-before-reuse 계약·native readback·fallback 불변.
