# 1.1.204 — Vulkan 읽기 메모리·오디오·JIT 작업 감소

2026-09-29. 릴리스 소스 커밋은 `5347a961225d91da25c34b610f6004e233edf4f3`다. SDL3·SDL2 패키지와 플랫폼 CI 검증을 완료했다.

## Vulkan 전체 화면 읽기

GPU 직접 표시나 native-origin 읽기만 사용하는 프레임에는 전체 화면 크기의 host-visible Vulkan 버퍼와 CPU 배열이 필요하지 않다. 두 저장소를 생성자에서 만들던 것을 Full/ReadbackView 첫 요청으로 미뤘다. 버퍼 준비는 명령 기록 전에 끝내며, 실패한 요청 뒤에도 native/GPU 경로와 재시도가 가능하다. 한번 만든 버퍼는 재사용한다.

캐시 가능한 mapped memory가 제공되면 원래 반환하던 포인터를 그대로 사용하고 중복 CPU 배열은 만들지 않는다. native 읽기의 고정 256×192 배열에도 같은 원칙을 적용했다. 캐시 불가능한 메모리에서는 기존 CPU 복사 fallback을 유지한다. 픽셀 계산·fence·표시 이미지 수명은 변경하지 않는다.

| 배율 | 전체 CPU 읽기 전 피하는 선할당 | Full 요청 후 cached 장치에서 계속 피하는 CPU 배열 |
| --- | ---: | ---: |
| 1배율 | 393,216 B (0.375MiB) | 196,608 B |
| 4배율 | 6,291,456 B (6MiB) | 3,145,728 B |
| 16배율 | 100,663,296 B (96MiB) | 50,331,648 B |

파이프라인 한 개의 요청 버퍼 범위와 CPU 배열 크기를 합산한 값이다. 실제 드라이버 heap/RSS 감소나 게임 FPS 측정값이 아니다. native cached 배열은 별도로 196,608 B를 피한다. 처음 전체 화면 읽기를 요청하는 시점으로 할당 비용이 이동한다.

## 오디오와 JIT

MinimumPhase dense 블록의 양 채널 누적을 한 함수로 묶어 같은 계수와 SIMD 선택을 공유한다. 중앙 패닝은 기존 단일 채널 경로를 유지하며 좌우가 갈라질 때의 이력 복사는 누적 전에 실행한다. 기존 AVX2/FMA·NEON·스칼라 기능 게이트와 채널별 연산 순서를 유지한다. GCC x64 출력의 스테레오 계수 벡터 읽기는 두 호출의 8회에서 한 호출의 4회로 줄었다. 계수·음색·지원 ISA는 바꾸지 않았다.

x64 JIT의 ARM BIC는 즉시값 반전을 컴파일 때 처리하고, Rn을 덮지 않는 목적지에서 직접 계산한다. 즉시값은 Rn과 목적지가 같으면 계산부 3→1명령, 다르면 4→2명령이다. 목적지가 Operand2와 같고 Rn과 다르면 4→2명령, 모두 다르면 4→3명령이다. 이미 시프트 임시값을 쓰거나 보존할 Rn이 목적지인 레지스터 경로는 유지한다. 게스트 사이클·shifter carry·NZCV·Thumb BIC 의미는 유지한다.

## 검증과 한계

- `gpu-vulkan-compute-spans`: 1·2·3배율의 기존 GL/Vulkan 전체 픽셀 대조 통과. 새 3배율 fixture는 전체 읽기 할당을 실패시켜 GPU/native 경로에 불필요한 할당이 없고, Full/ReadbackView 실패 뒤 재사용·재시도·새 프레임 픽셀이 보존됨을 확인한다.
- `gpu-vulkan-native-deferred`: 1·3배율 GPU 표시·CPU 요구·보존 전환·reset·미완료 소멸 검사가 통과했다.
- `core-jit-alu-shift`, `core-fastmem-alu-shift`: BIC를 기존 목적지 중첩·즉시/레지스터/시프트·부분 플래그 행렬에 추가했다. 두 검사 모두 ARM7·ARM9의 cold/cached 실행을 합쳐 7,812건씩 통과했다.
- MinimumPhase 및 SIMD 활성/비활성 기존 검사 통과. 실제 bank 352/512의 stream/renderer 기록은 1.1.203과 자동 SIMD·강제 스칼라 각각 669,259개, 4,406,620바이트 전부 일치했다. NEON 실장치 성능은 미측정이다.
- Windows x64·ARM64, Ubuntu, macOS, BSD, Core regressions CI가 모두 통과했다. 전체 검사는 CI에서만 실행한다.

사용 중인 PC의 다른 프로그램을 끄지 않았다. 추가 timing 벤치마크나 게임 플레이 검증은 하지 않았으며, 메모리·작업 감소를 FPS·지연·음질 개선으로 환산하지 않는다.
