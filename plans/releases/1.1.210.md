# 1.1.210 — Vulkan 캡처 팔레트 재사용·Sinc 출력 위상 공유

2026-09-29. SDL3·SDL2 패키지와 플랫폼 CI 검증을 완료했다.

## 변경

- Vulkan 캡처 텍스처: 공통 캐시가 이미 계산하는 팔레트 변경 여부를 네이티브 로더에 전달한다. 팔레트가 같으면 기존 128KiB 불변 GPU 입력을 재사용한다. 실제 변경은 디코드가 없는 업데이트에서도 이전 스냅샷을 폐기하며, 큐에 들어간 디코드는 이전 버퍼를 계속 소유한다. LCDC→텍스처 재캡처 과정의 일시적 매핑 해제에서는 유지하고 네이티브 파이프라인 비활성 시 해제한다.
- Sinc 최종 스테레오 출력: 두 계수 위상의 dot 네 개를 한 SIMD 루프로 계산한다. 좌·우 이력을 두 위상이 공유하며 결과별 누산·레인 합산·위상 보간·반올림·클램프 순서는 유지한다. AVX2/FMA·SSE2·ARM64 NEON 경로를 지원하고 스칼라 fallback은 기존 dot 네 번을 유지한다. 채널 보간과 필터 계수·탭·컷오프·레이트는 변경하지 않는다.

## 작업량과 한계

| 조건 | 1.1.209 | 1.1.210 |
| --- | ---: | ---: |
| 팔레트가 같은 다음 업데이트의 캡처 디코드 입력 | 128KiB 버퍼 재할당·CPU 복사 | 기존 입력 재사용 |
| 두 위상 스테레오 dot의 반복당 입력 벡터 읽기 | 6회 | 4회 |

팔레트 재사용은 네이티브 캡처 경로에 해당하며 일시적으로 캡처를 쓰지 않아도 활성 파이프라인에 128KiB를 유지한다. 변경이 잦으면 절감되지 않는다. SIMD 읽기 수는 GCC16 x64 AVX2/FMA·SSE2 생성 코드에서 확인했고 루프 안의 스택 spill은 없었다. Windows ABI의 함수 진입/반환 시 SIMD 레지스터 저장은 남는다. 물리 DRAM 트래픽·게임 FPS·구형 기기 전체의 속도·음질 향상률을 측정한 것은 아니다. 새 ISA/API 요구와 기본 설정 변경은 없다.

## 검증

- 실제 캡처→텍스처 디코드에서 소프트웨어 렌더러와 화면 전체가 일치한다. 소스 뱅크 재캡처 때 팔레트 할당 수가 늘지 않고, 녹색→청색 팔레트 변경은 새 버퍼와 픽셀에 반영된다. 그 사이 캡처 디코드가 없는 업데이트에서도 변경이 유실되지 않는다. 기존 뱅크별 무효화·CPU 기여분·GPU 소유권 전환 검사도 통과했다.
- 이전/새 `AudioSincOutput`의 AVX2/FMA·SSE2·각 강제 스칼라 구성에서 각각 483,596개 PCM 샘플 해시가 같다. 12개 입력/출력 레이트 조합, 난수·극값·임펄스·레이트 전환·reset·ring wrap과 출력 묶음을 포함한다.
- 기존 두 stereo dot와 새 네 결과의 부동소수점 비트를 직접 비교하는 검사를 추가했다. 서로 다른 tap 수·비정렬 입력·이력/계수 별칭을 포함하며 네이티브 ARM64 CI에서도 실행한다. 기존 오디오 출력 레이트·상태 복원·모드 전환 검사를 재사용한다.
- 로컬 집중 검사 3개가 통과했다. full suite는 CI에서만 수행한다. Windows x64·ARM64, Ubuntu, macOS, BSD, Core regressions CI가 모두 통과했다.
