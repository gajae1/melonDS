# 1.1.228 — 소프트웨어 2D 직접 색상 비트맵 BG의 SSE2 4픽셀 처리

2026-09-29. SDL3·SDL2 패키지와 플랫폼 CI 검증을 완료했다.

## 변경

소프트웨어 2D의 항등 아핀·직접 색상·비모자이크 BG2/BG3 비트맵 행에서 캡처 레이어가 비활성이고 컴파일러가 SSE2를 지원하면 4픽셀씩 벡터로 처리한다. 행·VRAM 경계는 벡터 읽기 전에 분할한다. 다른 아키텍처·캡처·모자이크는 기존 스칼라 경로를 쓰고 AVX2는 필요 없다(__SSE2__가 없는 MSVC는 스칼라). 이 이득은 클래식 GL과 공유하는 소프트웨어 2D 부분이며 새 Vulkan·GL 3D 변경은 아니다. 스칼라 패킹만 바꾸는 안은 혼합 사례에서 일관되지 않고 잡음 수준이라 기각했다. 새 외부 코드 도입 없이 이 포크에서 구현했다. 변경 파일은 src/GPU2D_Soft.cpp와 tests 3개다.

## 검증

- 비공개 helper 1552사례(65536색 전체 포함)가 스칼라 출력과 일치했다. 실제 렌더러 2592사례(엔진 2개·BG2/3·크기·클리핑·윈도 마스크·캡처·모자이크)는 기준 d359ff4와 출력 18579456바이트가 동일하다(sha256 77c78d74a5d81df11d44bd52ea0ea3f93f81bfdb3f23e50ef29152cab3db1729). 영구 테스트가 이 기준 해시를 쓴다. 집중 테스트 2개(software-text-bg-output, software-bitmap-bg-output)는 1.02초에 통과했다.
- 내장 DS 소프트웨어 1배율 Sinc6 ROMSmoke 1200프레임 2건(Black·Solatorobo)의 프레임버퍼·PCM 해시가 1.1.227과 일치했다. 게임 플레이·물리 입력·오디오는 하지 않았다.
- 전체 회귀는 CI에서만 수행한다. Windows x64·ARM64, Ubuntu, macOS, BSD, Core regressions CI가 모두 통과했다.

## 측정

실제 렌더러 합성 벤치: 프로세스 A/B 4쌍 교차, 워크로드당 웜업 1회 후 5회 측정, 회당 12000 draw call, 엔진 A/B × 불투명·혼합 알파·혼합 윈도·전체 마스크 8조건. 쌍별 경과 시간 중앙값이 23.02~67.19% 낮았다. 현재 9800X3D의 바쁜 호스트에서 A/A 절대 중앙 변동은 워크로드별 4.21~28.92%였고 8조건 모두 자기 A/A 중앙값을 넘었다. 이는 통계적 유의성이 아니다. 게임 FPS·다른 CPU/GPU·오디오·입력은 주장하지 않는다.  227의 Black 표본 프로파일에서 확장 BG 표본 112개 중 107개가 이 루프였으나 이는 자기 시간 표본이며 전체 CPU 사용률이 아니다.
