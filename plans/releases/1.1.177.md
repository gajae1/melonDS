# 1.1.177 — ARM9 SWP/SWPB JIT 컴파일, JIT 쓰기 주소 인라인, 배포 PE 검사

2026-09-24. 이전 버전은 1.1.176이다. 기본 배포는 SDL2이고 SDL3는 `ENABLE_SDL3=ON` 선택형 빌드다.

x64 JIT은 이제 ARM9의 SWP/SWPB를 블록 안에서 직접 실행한다. 이전에는 이 명령마다 인터프리터 도우미로 빠져나갔고, 1.1.176 프로파일에서 Black 실행 시간의 1.4~2.8%를 차지했다. 읽기는 LDR과 같은 경로(fastmem, 예외 재실행, 레지스터 캐시)를 쓰고, 쓰기는 인터프리터와 같은 `SlowWrite9`로 한다. 저장 값은 원래 Rm, 주소는 원래 Rn이며, 쓰기 권한이 거부되면 Rd는 바뀌지 않는다. 두 접근의 사이클은 인터프리터와 같은 합계로 한 번에 더한다. PC를 쓰는 인코딩과 ARM7은 기존 도우미를 그대로 쓴다. SysV에서는 권한 검사가 쓰는 `RSCRATCH2`가 세 번째 인자 레지스터와 같으므로, 저장 값은 권한 검사 뒤에 읽는다. 새 `core-*-swap` 검사는 서로 다른 레지스터, Rd=Rm, Rd=Rn, 비정렬 워드, SWPB, 조건 불성립 SWP를 인터프리터·JIT·fastmem에서 확인한다. 같은 코드를 세 번 실행해 두 번째부터 컴파일된 코드를 거치게 했고, 저장 값을 Rd로 바꾼 변이를 JIT·fastmem에서 잡는 것도 확인했다. Black 2400프레임 교대 측정 24쌍에서 중앙값 4.0% 짧아졌고(23/24 우세, A/A 0.9%), 1200프레임 동안 19,687,009회가 네이티브 코드로 옮겨졌다.

JIT 코드 영역 쓰기 검사는 MainRAM·VRAM·ARM7 WRAM처럼 주소 변환이 고정 마스크인 영역의 지역 주소를 호출 없이 인라인으로 계산한다. 공유 WRAM·DSi NWRAM 등 매핑에 따라 달라지는 영역은 기존 `LocaliseAddress`를 그대로 쓴다. 3,950만 회 쓰기 검사의 지역 주소, 무효화 순서와 제거 블록이 같았고, Black 32쌍에서 중앙값 1.54% 빨라졌다(A/A 0.70%). Solatorobo는 검사 횟수가 4분의 1이라 차이가 없었다.

Windows 배포 스크립트는 명백한 x64 PE 헤더(MZ/PE 서명, machine 0x8664, 선택 헤더 크기, 섹션 표 길이)를 직접 읽어 수락하고, 그 밖의 입력은 기존 `objdump -f` 경로로 판정한다. 실제 배포 바이너리 258개와 조작 입력 100개에서 판정이 같았고, SDL2·SDL3 배포 트리가 바이트 단위로 같았으며, 아키텍처 검사 시간은 2.6초에서 14ms로 줄었다.

비공개 게임 두 개의 헤드리스 Software 1200프레임 ABBA 실행에서 1.1.176과 1.1.177의 최종 화면·누적 PCM·프레임버퍼 digest가 같았다. SWP 변경은 두 게임을 JIT·인터프리터·fastmem 해제 조합으로 돌려 digest가 HEAD와 같음을 따로 확인했다.

1.1.176 코드로 다시 잰 프로파일(`local-docs/profile-hotspots-176-20260924`)의 다른 후보는 채택하지 않았다. 비-fastmem ARM9 데이터 경로는 fastmem이 이미 켜져 있었고, MainRAM 쓰기 중복 조회 제거가 0.2% 느렸다. 블록마다 도는 타이머 갱신은 호출의 98% 이상에서 타이머가 실제로 동작해 조기 종료가 무의미했고, 인라인화는 잡음 안이었다. SPU 믹스의 무음 채널 생략은 해당 함수에서 15~65% 빨라졌지만 최소 위상 경로에서는 전체 차이가 잡음과 구분되지 않았다. Software 2D BG 창 마스크 구간 처리는 부분 마스킹 행이 6~14% 느려졌다.

소스 커밋 `f4c4c0e796f227411521c125a3cdb82b5b0c46a3`의 깨끗한 스냅샷에서 Windows UCRT64 Release를 SDL2·SDL3로 각각 빌드했다. SDL2 전체 CTest는 새 SWP 검사 3개를 포함해 **1026/1026**, SDL3 오디오·입력 집중 CTest는 **48/48**이다. 두 배포·패키징은 exit 0이고 두 매니페스트의 소스 ID는 `daebd21f1c0f11e6fb514ff5b16ed86553c1227411f13fcc9d6a368502460e66`로 같다. 각 런타임 ZIP은 325개 파일, 검사한 비공개 파일 0개이며 기본 ZIP에는 SDL2 DLL만, 선택형 ZIP에는 SDL3 DLL만 있다. 다른 작업자의 수정된 `src/teakra/src/test_generator.cpp`는 포함되지 않았다.
