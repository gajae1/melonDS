# 1.1.136 — 캡처 비트맵 서브픽셀 조회 비용 절감

기준은 1.1.135 af3c3980, 제품 변경은 cfa30735다. 동일 배율의 1:1 정수 affine BG2/BG3에 대해 캡처 매핑·provenance·행 유효성을 subx 루프 전에 조회한다. 조회 결과 포인터는 현재 ComposeCapturedLine 호출 안에서만 쓰며 색은 서브픽셀마다 따로 읽는다. 다중 bank, 무효 캡처, 배율 불일치, 일반 affine는 기존 샘플러로 처리한다. native VRAM 기록과 합성 순서는 변경하지 않는다. 여러 텍셀을 하나의 span으로 합친 구현은 아니다.

## 검증

Windows UCRT64 Release에서 melonDS와 VulkanRendererIntegration 빌드 성공. 커밋 cfa30735의 gpu-vulkan-capture-bitmap-bg 통과(16.81초); 양 engine, 2/3/5/8배의 affine·우선순위·효과·창·모자이크·무효화 조건을 기존 fixture로 확인했다. gpu-vulkan-renderer 및 2x/3x, gpu-vulkan-capture-display, gpu-software-2d-composite도 5/5 통과(7.04초). 마지막 software 대조는 기존 실행 파일이며 최종 후보의 전체 코어 재링크 회귀로 집계하지 않는다.

재빌드한 1.1.135 기준 실행 파일과 후보를 동일 논리 CPU에서 번갈아 실행했다. 기존 bitmap-benchmark의 4프레임 준비·16프레임 측정, 배율별 준비 1쌍 제외 후 3쌍 중앙값이다. 이 수치는 engine A의 합성 workload이며 실행 순서는 교대 방식이다.

| 배율 | 기준 | 후보 | 감소 |
|---|---:|---:|---:|
| 3x | 15.255 ms | 7.934 ms | 48.0% |
| 8x | 81.237 ms | 43.793 ms | 46.1% |

양 화면의 합산 checksum은 배율별 모든 실행에서 같았다(3x 3796583701183488, 8x 26997928541749248). 합산값은 모든 픽셀의 바이트 동일성 증명이 아니다. 독립 전체 버퍼 비교, engine B 성능, 일반 affine의 성능, 실게임 FPS, 다른 GPU/OS·DSi·장기 사용은 미검증이다. 이번 최종 후보에 전체 971개 통과를 귀속하지 않는다. 이전 실패한 후보의 측정·검사를 섞지 않는다.

후보 실행 파일 SHA256: A49B63F59C188F282670C9B9D8F541D0647E03D12781A8C2B10F47044BE9068B.
로컬 원시 측정: local-docs/bitmap-hoist-benchmark.json. 위 해시는 버전 표기 갱신 전 제품 변경의 검증 실행 파일이다.

## 남은 범위

캡처 OBJ·3D texture 재사용, 실제 연속 span 묶음, GPU 2D·직접 표시는 후속이다.

## 2026-09-18 배포 확인

버전 표기를 포함한 7ad4f0c8에서 melonDS·VulkanRendererIntegration 빌드가 종료 코드 0으로 끝났다. 해당 실행 파일로 renderer 1x/2x/3x, capture-display, capture-bitmap-bg의 선택 회귀 5/5가 22.65초에 통과했다. 전체 suite 재실행으로 집계하지 않는다.

기존 deploy-windows.py와 package-windows.py로 build/1.1.136-packages에 Windows x64 runtime ZIP(103,883,159바이트)과 source ZIP(18,234,889바이트)을 생성했다. source ZIP 기준 커밋은 7ad4f0c83e840fa1195210dfcd776b5e83a20c55다. 배포 manifest 325파일의 SHA-256 대조, ZIP 무결성, 실행 파일 source identity, 깨끗한 PATH의 도움말 실행(종료 코드 0)을 통과했다. ZIP 내 알려진 개인 파일은 0개다. 라이선스는 설치 버전·해시를 검증하는 기존 supplement를 재사용했다. 번역 catalog 및 D3D12 dxcompiler/dxil 부재 경고는 남으며 GL/Vulkan 배포 검증을 D3D12 지원 증거로 세지 않는다.

Runtime ZIP SHA-256: a79d4a4e8074d809881c24bbadab2ad57258603ef1f784157a16be415a283fa9.
Source ZIP SHA-256: 25fdc2f0873227c2360e14b4f4559f95bb2a8dc4ab3469fa19f632d20eeb788c.

2026-09-18 2차 provenance 확인: runtime·source ZIP SHA-256을 자체 1.1.136 manifest와 대조해 일치했고 두 ZIP 모두 무결성 검사를 통과했다. runtime ZIP은 325개 항목이며 release-version.txt는 1.1.136이고, ZIP 내부 EXE SHA-256(afe7f16a5231d7dded3102657759401742c15e958688977afc5a5c170a93acaa)은 1.1.136 manifest와 deployment manifest와 일치한다. source ZIP은 1,310개 항목에 이 문서를 포함하고, CMakeLists.txt와 src/GPU2D_Soft.cpp는 CRLF 정규화 후 커밋 7ad4f0c8 blob과 byte-identical하다. 정규화 전 불일치는 개행 차이뿐이며 5eea9164는 이 문서만 수정하므로 7ad4f0c8 이후 CMake 변경은 없다.

패키지 바이너리 행동 검증은 이 세션에서 재실행하지 않았다. 문서 기록의 2026-09-18 선택 회귀 5/5(22.65초)를 증거로 재사용하며, 안전 테스트 ROM(build/graphics-hardware-probe-01/depth-aa-probe-01.nds)을 이용한 패키지 바이너리 직접 행동 확인은 미수행으로 남는다. GUI 바이너리 직접 실행은 소유 범위 밖 설정 파일 접근 가능성 때문에 범위 내 실시 불가로 판단했다.
