# 1.1.227 — OpenGL Compute 텍스처 Modulate 배치의 래스터·깊이 블렌드 융합

2026-09-29. SDL3·SDL2 패키지와 플랫폼 CI 검증을 완료했다.

## 변경

1.1.227은 OpenGL Compute에서 폴리곤 1~8개·텍스처 Modulate variant 하나·TileSize 8·1~4배율(캡처 텍스처 포함) 배치의 래스터를 깊이·블렌드 셰이더에 융합한다. 해당 배치는 간접 래스터 dispatch와 장벽, 중간 타일 색상·깊이·속성 접근을 생략하고 기존 텍스처 바인딩 루프를 그대로 재사용한다. Fog·AA 같은 최종 효과는 별도 패스다. OpenGL 셰이더 프로그램은 1~4배율에서 34→36개가 되었고 Vulkan 48개는 그대로다. 융합 배치의 clear 텍스처는 유닛 3·4에, 일반 텍스처·캡처 128·캡처 256은 각각 유닛 0·1·2에 바인딩한다.

지원하지 않는 variant·타일 크기·배율은 기존 경로를 쓴다. 보호 대상인 기존 OpenGL 렌더러(GPU3D_OpenGL.cpp)는 바꾸지 않았고 새 외부 코드는 없다.

## 검증

- 변경한 5개 소스 파일의 최종 diff를 한 번 검토해 수락했다. 파일 해시는 source-review.json에 있고 줄 끝 정규화 후 소스 커밋과 일치한다.
- 12개 집중 검사가 모두 통과했고 전체 경과 시간은 16.43초다(초: gpu-vulkan-compute-spans 4.42, gpu-compute-frame-capture 2.31, gpu-gl-texture-alpha-compute 1.83, gpu-gl-texture-blend-compute 0.74, gpu-gl-texture-shading-compute 0.55, gpu-gl-texture-capture-compute 0.85, gpu-gl-texture-bitmap-compute 0.78, gpu-gl-texture-compressed-compute 1.56, gpu-compute-workload-blend 1.03, gpu-compute-workload-single-variant 1.59, gpu-compute-failure-recompile 0.37, gpu-gl-resource-normal 0.36).
- 게임 플레이와 설치 앱 조작은 하지 않았다. 전체 회귀는 CI에서만 수행한다. Windows x64·ARM64, Ubuntu, macOS, BSD, Core regressions CI가 모두 통과했다.

## 측정

실제 제품 GLRenderer Start3DRendering의 GPU 경과 시간을 AMD Radeon 한 GPU에서 합성 96사례(일반·캡처 128·캡처 256 텍스처 각 32사례)로 측정했다. 96사례 모두 픽셀이 일치했고 실제 간접 dispatch는 기준 1회·후보 0회임을 확인했다. 웜 반복 20회, 교차 순서 40쌍 관측의 GPU 쌍별 중앙값은 사례 중앙값 기준 19.53% 낮았고(3.97~60.51%) 96사례 모두 각자의 A/A 변동을 넘었다. A/A 중앙 변동의 최댓값은 7.86%다.

| 텍스처 | 사례 | 감소 중앙값(%) | 범위(%) |
| --- | ---: | ---: | ---: |
| 일반 | 32 | 19.27 | 3.97~60.51 |
| 캡처 128 | 32 | 19.72 | 4.18~60.33 |
| 캡처 256 | 32 | 19.53 | 4.71~60.03 |

GPU 경과 시간에는 CPU 제출 간격이 포함된다. CPU 시간·게임 FPS·물리 입력·오디오 지연·Metal 비교는 주장하지 않는다. 원본은 probe/product-comparison.json, product-ab.json, product-aa.json이며 세 파일의 사례 키와 해시가 일치한다.
