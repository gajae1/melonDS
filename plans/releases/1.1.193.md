# 1.1.193 — 오디오·OpenGL 작업 감소와 Thumb JIT 사이클 수정

2026-09-28. 릴리스 소스 커밋은 c89e62855ea2d23867468dc1e44e7b243593c6cd다. SDL3·SDL2 패키지와 플랫폼 CI 검증을 완료했다.

## 반영한 변경

| 영역 | 변경과 확인 범위 |
| --- | --- |
| MinimumPhase 오디오 | 희소 이력을 읽을 때 구조체를 복사하지 않고 참조한다. 계수·계산 순서·ISA 선택은 같다. SPU 객체에서 기록당 40바이트의 임시 stack write가 사라진다. |
| OpenGL 표시 | 같은 레이아웃 잠금 안에서 불투명 화면 사각형의 합집합이 창 전체를 덮는지 확인한다. 완전히 덮을 때만 배경 clear를 생략하고 틈·letterbox·표시 불가 상태는 기존 clear를 유지한다. |
| x64 JIT | 추적 때 taken이었던 Thumb 조건 분기가 나중에 not-taken side exit로 빠질 때 fetch 1사이클을 먼저 누적한다. 기존 코드에서 ARM9·ARM7 모두 0사이클이 기록되던 반례를 재현했다. |
| Vulkan 빌드 | 생성 GLSL 내용이 같으면 파일을 다시 쓰지 않고 각 SPIR-V를 해당 GLSL에 의존시킨다. 기존 512개 일괄 재컴파일 비용을 줄이며 렌더링 셰이더 내용은 바꾸지 않는다. |

구현 커밋은 오디오 4f67ea0a, 빌드 b0657956, JIT 66757faa, OpenGL d08a76a3다.

## 측정과 보류

- MinimumPhase 16채널 희소 입력·interval 512 커널의 스레드 사이클은 5쌍 모두 감소했고 쌍별 중앙값 −17.47%다. 같은 바이너리 A/A 절대 중앙값 1.88%, 범위 −5.47~+1.88%였다. CPU 4에 고정한 독립 커널 측정이며 전체 게임 FPS·음질·출력 지연 개선율이 아니다. interval 352와 dense 입력은 개선을 확정하지 않았다.
- OpenGL의 6가지 레이아웃×2필터는 실제 clear가 전체 coverage에서 1→0회, 빈 공간이 있으면 1회다. 모든 49,152픽셀이 강제 clear 기준과 같았다. 드라이버의 fast clear 비용과 전체 프레임 시간 이득은 미측정이다.
- Vulkan 픽셀 사전검사는 Radeon Solatorobo 4배율에서 GPU 3D 시간 −4.57%(5쌍, A/A 절대 중앙값 0.124%)였으나 전체 프레임 이득은 없었다. RTX 3쌍 대조는 GPU 3D +4.92%, Radeon CoD는 사실상 변화 없음(+0.004%)이었다. 덮인 픽셀의 이중 순회 비용 때문에 공통 경로에 채택하지 않았다.
- 소프트웨어 2D 후보는 native helper 호출 8곳이 사라지고 화면·오디오가 같았지만 시간 측정 변동이 커 보류했다. 두 보류 후보의 패치와 부정적 측정은 보존한다.

## 남은 범위

새 고급 ISA 요구를 추가하지 않았다. 기존 SSE2/AVX2/FMA/NEON·스칼라 dispatch를 유지한다. 오래된 실제 PC의 전체 게임·청취, ARM64 실장치 성능, Mac Metal 상대 성능은 이번에 측정하지 않았다. OpenGL 최적화가 끝났다는 근거는 없으며 Vulkan GPU 2D·1배율 RAM 경로 제거도 후속이다. [참고 프로젝트 반영 현황](../Reference_Adoption.md)을 함께 읽는다.
