# 1.1.201 — Vulkan 최종 배치 합성 셰이더 정적 특수화

2026-09-29. 릴리스 소스 커밋은 `0555cb074fce438754bee653babcff1a4746349a`다. SDL3·SDL2 패키지와 플랫폼 CI 검증을 완료했다.

## 변경

OpenGL compute 경로는 후속 배치에서 빈 타일을 만나면 남은 작업을 하지 않고 조기 반환한다.

Vulkan은 에지 마킹이 꺼진 최종 배치에서만 DepthBlend·포그/AA·RGBA 출력을 하나의 셰이더로 합친다. 셰이더와 pipeline 배열은 Vulkan 전용 정적 특수화 변형 8개를 더해 Vulkan 40개를 쓰고, OpenGL은 기존 32개를 유지한다. 에지 마킹이 켜진 경로는 기존처럼 별도 최종 패스를 유지한다.

융합 최종 변형은 DepthBlend 중간 결과를 결과 버퍼에 저장하지 않고(변형 3은 7곳, 융합 변형 32·34·36·38은 0곳, 이미지 쓰기 1곳) 별도 최종 dispatch도 피한다. 이는 구조적 감소이며 FPS 향상이 아니다. GPU pipeline 시작 자원은 늘어나고 새 ISA·API 요구는 없다.

## 검증과 남은 범위

- 집중 최종 그래프 차등 검사가 Windows offscreen 실제 GPU에서 통과했다. 모든 효과 조합과 빈 최종 배치를 포함해 GL과 Vulkan의 1배율 Z·W 스팬과 장면 픽셀이 일치했고 3.91초에 끝났다.
- 두 GPU의 Solatorobo 4배율 시작 1200프레임 최종 framebuffer SHA가 1.1.200과 같다.
- A/B/A 최종 확인에서 Radeon 3D는 7.826371, 6.898131, 6.913249ms, RTX 3D는 0.246488, 0.242914, 0.252759ms였다. Radeon 기준 A끼리의 변동이 컸으며 RTX의 native 2D 단계는 0.080287, 0.083709, 0.080840ms로 후보가 조금 느렸다. 짧은 단회 A/B/A이므로 전체 FPS 개선을 입증하지 못했다. 이전 동적 후보의 기준 A/A 시간 변동 20.8%와 RTX 3D 약 4.85% 감소는 최종 정적 후보의 성능 수치로 사용하지 않는다.
- Windows x64·ARM64, Ubuntu, macOS, BSD, Core regressions CI가 모두 통과했다.
