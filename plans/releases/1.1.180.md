# 1.1.180 — 소프트웨어 2D 스프라이트·합성 단축, README 상태 표기

2026-09-25. 이전 버전은 1.1.179이다. 기본 배포는 SDL2이고 SDL3는 `ENABLE_SDL3=ON` 선택형 빌드다.

소프트웨어 2D 렌더러의 스프라이트 처리와 최종 합성을 줄였다(HS-7). 한 줄에 불투명 OBJ 픽셀이 없는 우선순위는 256픽셀 인터리브 패스를 건너뛴다. 이를 위해 줄마다 실제로 쓰인 불투명 OBJ 우선순위를 비트 마스크로 모으며, 마스크는 항상 실제 집합을 포함하므로 건너뛰는 패스는 아무 픽셀도 바꾸지 못하는 패스뿐이다. 스프라이트 슬롯은 크기표를 읽기 전에 최대 경계 128줄 밖이면 제외한다. 기존 경계 검사와 결과가 같다. target2 블렌드가 없고 target1 일부만 고른 밝기 효과는 한 줄 단위 마스크 루프로 합성한다. 두 번째 샘플이 결과에 쓰이지 않으므로 밝기만 가능한 효과이고, 플래그→target 비트 대응은 기존 `CompositePixel`과 같다. 914,653,184개 입력의 차분 비교에서 기존 합성과 불일치 0건이었다. 구역 계측에서 InterleaveSprites −65.2%, ColorComposite −43.7%, DrawSprites −11.2%, 소프트웨어 2D 전체 −23.2%였고 Solatorobo 소프트웨어 4800프레임 실행 시간은 두 번의 독립 반복에서 중앙값 −2.0%, −3.1%였다. 근거는 `local-docs/s2d-sprite-compose-20260925/`에 있다.

README의 fork 릴리스 배지를 갱신하고 원본 TODO 목록 각 항목 옆에 현재 상태(원본에 이미 있는 기능, 포크의 부분 진행, 미착수)를 표기했다.

같은 라운드에서 다음 후보는 채택하지 않았다.

- 오디오 보간 뱅크 지연 전개: 뱅크 생성은 38.9ms에서 3.2ms로 줄고 표는 바이트 동일했지만, 1.1.180 후보 전체 비교에서 1200프레임 실행이 Solatorobo 2.62→3.00초, Black 1.63→2.01초로 느려졌다. 스프라이트 변경만 넣은 빌드는 2.56초·1.65초로 1.1.179와 같아서 원인을 이 변경으로 분리했다. 가장 뜨거운 보간 경로에 들어간 첫 사용 검사와 `std::deque` 색인이 원인 후보다. 패치는 `local-docs/audio-bank-startup-20260925/rejected-lazy.patch`, 분리 측정은 `local-docs/release-180-20260925/bisect/`에 있다.
- JIT 블록 모양 결정화(BV-17 Black): 저장 상태 바이트 일치와 IRQ 진입 시점 일치를 달성했지만 쌍별 중앙값이 Black +9.98%, Solatorobo +4.16% 느려졌다. `local-docs/jit-block-shape-determinism-20260925/`. BV-17 Black 수락은 여전히 미완료다.
- JIT 쓰기 무효화 사전 검사: 정확 검사 횟수를 99.93% 줄이고 무효화 결정은 같았지만, 검사 경로 전체를 없앤 상한도 약 1%라 속도 차이가 잡음 이하였다. `local-docs/jit-inval-pretest-20260925/`.

비공개 게임 두 개의 헤드리스 Software 1200프레임 ABBA 실행에서 1.1.179와 1.1.180의 최종 화면·누적 PCM·프레임버퍼 digest가 같았다.
