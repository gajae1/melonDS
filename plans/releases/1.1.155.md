# 1.1.155 — SDL3 opt-in 빌드·frontend 경계 수정

2026-09-22. 기준 1.1.154 HEAD 690d9ca0. 빌드는 93f6 worktree의
build/windows-dev다.

## 구현 — 1.1.154 이후 누적 변경

빌드/이식성:

- BV-20 첫 이행: ENABLE_SDL3 CMake option(기본 OFF)과 SDLCompat.h
  dual-source port. 소스는 SDL3 API 표면으로 작성하고 OFF에서는 SDL2로
  매핑한다. audio/mic stream·장치 열거·rumble property·entry point 등
  모델이 바뀐 곳만 실 ifdef. SDL3 배포 실행은 SDL 이름 하드코딩 없이
  PE import closure로 SDL3.dll·LICENSE를 자동 포함함을 확인.
- BV-12의 유일 공백이던 interpolation 런타임 fallback 추가:
  MELONDS_INTERPOLATION_SCALAR=1이면 가속 kernel 대신 scalar 경로를
  강제한다(환경 변수 opt-in, 테스트 seam).

frontend 경계(FS-21·BV-19·FS-11):

- 카메라 미리보기 수명을 CameraSettingsDialog가 소유: 창 닫힘/무응답
  소멸 시에도 설정 복원·미리보기 정지·singleton 해제. Qt6
  videoInputsChanged로 hotplug 재열거·선택 보존, 장치 소실 시 마지막
  프레임 유지, QCamera error를 로그로 표면화.
- Wifi/DSi SD/DLDI 실패 가시성: NetDriver::IsActive·
  Net::HasActiveDriver/WarnUnavailableOnce로 드라이버 가용 상태를
  추적하고 NetInit 실패 사유 기록·stale 드라이버 해제·OSD 경고·
  Wifi 설정 Status 행을 추가.
- 화면 배치 계약: 정수 배율이 1x 미만에서 0으로 붕괴하던 것(3곳),
  emphasized sizing의 협소 창 분기가 보조 화면을 1x로 고정하고 주 화면을
  음수 배율로 계산해 창 밖으로 출력하던 것, 홀수 창 크기의 정수 나눗셈
  중심 오차를 수정. 전 layout×rotation×sizing×gap×integerScale×swap
  조합의 변환 유한성·창 경계·터치 역변환·degenerate 크기를 고정하는
  screen-layout ctest 4개 추가.

기록: BV-20 SDL3 이행 표면 인벤토리(93 심볼), AD-21 DSP HLE/LLE 비교
경계, 1.1.154 패키지 검증.
