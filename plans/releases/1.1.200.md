# 1.1.200 — x64 JIT 곱셈 복사 감소

2026-09-29. 릴리스 소스 커밋은 `1bc7bd87ea022b5eb392fb5071585b475085f91b`다. SDL3·SDL2 패키지와 플랫폼 CI 검증을 완료했다.

## 변경

MUL·MULS·Thumb MUL은 EAX에서 곱한 뒤 목적지로 복사하던 경로를 목적지 직접 계산으로 바꾼다. 목적지가 Rs와 같으면 곱셈의 피연산자 순서를 바꿔 MOV가 원래 Rs를 덮어쓰지 않게 한다. MLA는 목적지가 누산기 Rn과 같으면 기존 scratch 경로를 유지한다. 누산기와 다를 때만 목적지에서 곱한 뒤 Rn을 더한다. 플래그 계산과 ARM7·ARM9 guest 사이클 처리는 유지한다.

계산부 기준 MUL은 기존 3명령에서 독립 목적지 2명령, 피연산자와 겹치는 목적지 1명령으로 줄어든다. Thumb MUL은 1명령이다. MLA는 목적지가 피연산자와 겹치면서 누산기와 다를 때 3→2명령이고, 나머지 경우의 명령 수는 같다. 게임 FPS나 구형 CPU의 속도 향상률은 측정하지 않았다.

## 검증과 기각한 후보

- `core-jit-execution`, `core-jit-fastmem-execution`이 통과했다. 기존 multiply 행렬의 Rs·누산기 중첩, Thumb 자체 곱셈, 조건 실행, live NZ, 경계값·사이클을 유지하고 ARM Rm 중첩을 추가했다.
- 별도 Vulkan hires-writer 검사는 비동기 렌더 완료 전에 참조 ColorBuffer를 읽고 복원하던 오래된 fixture 가정 때문에 1.1.199에서도 실패했다. 두 참조 장면의 완료를 명시한 뒤 기존 assertion 그대로 2·3배율 7,168개 확대 halfword와 1,024개 native halfword가 일치했다. 4,264개 확대 값이 native와 달라 guest/display 분리가 실제로 검증됐으며, 제품 Vulkan 코드는 바꾸지 않았다.
- GPU2D 상수 픽셀 분기 후보는 두 Radeon 4배율 단회 쌍에서 이득이 없어 제거했다. 측정 쌍이 적어 확정적인 회귀율로 주장하지 않는다.
- MinimumPhase 주기 캐시 후보는 auto·scalar 각각 669,259개 레코드가 동일했지만 희소 16채널 측정 세 쌍 모두 느려 제거했다. 계수·음색·음질을 변경하지 않았다.
- Windows x64·ARM64, Ubuntu, macOS, BSD, Core regressions CI가 모두 통과했다. 전체 검사는 CI에서만 실행하며 수동 플레이와 장시간 ROM 실행은 추가하지 않았다.
