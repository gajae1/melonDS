# 1.1.173 — Software 3D 행별 활성 폴리곤 순회

2026-09-24. 이전 버전은 1.1.172다. 기본 배포는 SDL2이고 SDL3는 `ENABLE_SDL3=ON` 선택형 빌드다.

Software 3D 래스터라이저는 192개 행마다 설정된 폴리곤 전체(최대 2048개)의 `Polygon` 구조체를 따라가 Y 범위를 검사했다. 이제 프레임마다 시작 행·종료 행 목록을 한 번 만들고, 각 행에서 2048비트 활성 마스크를 낮은 인덱스부터 순회한다. 그리는 순서는 기존 목록 순서와 같다. 판정 범위는 기존 조건과 같은 `[YTop, YBottom)`이며, 수평 폴리곤은 `YTop` 한 행, `YBottom < YTop`인 비정상 상태는 그리지 않는다. 화면 밖 값은 0~191행으로 자른다.

현재 HEAD 렌더러를 다른 클래스 이름으로 함께 링크한 비공개 대조 하네스에서 128개 순차 프레임과 24개 스레드 프레임의 행 출력, color·depth·attr·stencil 버퍼가 모두 일치했다(불일치 0). 장면에는 기존 GR-09 10종과 63·64·65·127·500·1024·2047·2048개의 작은 폴리곤, 수평·마지막 행·완전 높이 폴리곤, 섀도 마스크/섀도 교차가 포함된다. 수평 폴리곤 누락, 64개 단위 순서 뒤집힘, 마지막 행 누락 변이는 모두 검출됐다.

같은 하네스의 10쌍 교대 측정(렌더 스레드 사이클 중앙값)에서 작은 폴리곤 2048개 장면은 18.09→15.67M(−12.9%, 10/10), 500개는 −10.0%(10/10), 섀도 마스크 2048개는 −15.6%(10/10), 12~36행 높이 512개는 −4.6%(8/10) 줄었다. 화면 크기 폴리곤 12~24개 장면의 변화는 −0.5%~+1.5%로, 후보끼리 비교한 A/A 대조의 배치 편향 +1.0%~+2.9% 안에 있다. 이는 합성 부하의 결과다. 비공개 게임 두 개의 헤드리스 Software 1200프레임 ABBA 실행에서 최종 화면·누적 PCM·프레임버퍼 digest는 1.1.172와 같았고, 실행 시간 차이는 잡음 범위였으므로 게임 FPS 향상은 주장하지 않는다.

SDL2 전체 CTest **1023/1023**, SDL3 오디오·입력 집중 CTest **48/48**을 통과했다. 두 배포·패키징은 exit 0이며 두 매니페스트의 소스 ID는 `e26e3ed7766e812e0c998c2a2b2329445d40ca46367de2a6648ffbc28fdd7320`로 같다. 각 런타임 ZIP은 325개 파일, 검사한 비공개 파일 0개이고 기본 ZIP에는 SDL2 DLL만, 선택형 ZIP에는 SDL3 DLL만 있다. 다른 작업자의 수정된 `src/teakra/src/test_generator.cpp`는 커밋·소스 ZIP에 포함되지 않았다.
