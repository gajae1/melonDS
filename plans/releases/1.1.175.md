# 1.1.175 — MPU 동일 쓰기, 무텍스처 UV, 캡처 합성, 간접 버퍼 바인딩, Vulkan 인덱스 크기 최적화

2026-09-24. 이전 버전은 1.1.174이다. 기본 배포는 SDL2이고 SDL3는 `ENABLE_SDL3=ON` 선택형 빌드다.

CP15는 MPU 영역 레지스터에 저장된 원시 값과 같은 값을 다시 쓸 때 MPU 권한 표 재구성을 건너뛴다. 값이 달라지는 쓰기와 다른 CP15 상태 변경은 이전처럼 재구성한다. 동일 쓰기 반복 부하는 426ms에서 0.72ms로 줄었고(8/8쌍), 일반 쓰기 경로의 결과 상태는 바이트 단위로 같았다.

Software 3D는 텍스처가 없는 폴리곤에서 픽셀마다 UV를 보간하지 않는다. UV를 읽는 경로가 없는 경우에만 생략하므로 출력은 그대로이며, 4,570만 워드를 비교해 불일치가 없었다. 합성 장면에서 −4~−19%(불투명 장면 −19%, 12/12쌍)였다.

Software 2D의 캡처 레이어 합성은 행 안에서 바뀌지 않는 후보를 미리 계산한다. 1.42GB 출력이 바이트 단위로 같았고, 전부 정적인 장면 −90~−98%, BG 하나 약 −53%, 혼합 장면 약 −5%였다.

Compute 렌더러는 루프 안에서 같은 간접 버퍼를 반복 바인딩하던 호출을 제거했다. 변이가 많은 두 장면의 CPU 발행 시간이 −9.7%, −11.6%(10/10쌍)였고 변이가 적은 장면은 차이가 없었다. Vulkan 설정 단계는 인덱스 배열을 화면 전체 높이 대신 계획된 span 수만큼만 채운다. 16배 해상도 2048폴리곤 혼합 장면이 14.9ms에서 11.6ms가 됐고(8/8쌍) 전체 높이 대조군은 변화가 없었다. 모든 수치는 함수 단위 합성 부하이며 게임 FPS 향상은 주장하지 않는다.

비공개 게임 두 개의 헤드리스 Software 1200프레임 ABBA 실행에서 1.1.174와 1.1.175의 최종 화면·누적 PCM·프레임버퍼 digest가 같았다.

같은 라운드에서 DS MainRAM DMA 특수 경로는 동일성은 통과했지만 ARM7 고정 소스 대체 경로가 중앙값 8.5% 느려져(A/A 잡음 1.9%) 채택하지 않았다.
