# 1.1.182 — Vulkan 직접 표시, 밝은 Sinc 오디오, ARM64 JIT 블록 연결

2026-09-26. 이전 버전은 1.1.181이다. 기본 Windows 배포는 SDL3이고, SDL2 빌드는 `-sdl2` 접미사 ZIP으로 함께 낸다.

**Vulkan 직접 표시.** Vulkan 렌더러와 Vulkan 화면 출력을 함께 쓰면 표시 창이 렌더러의 GPU 이미지를 같은 장치에서 바로 샘플링한다. 이전처럼 이미지를 RAM으로 읽어 와서 창 크기 QImage로 CPU 확대하지 않는다. 확대, 필터, 회전, 검은 배경은 작은 표시 셰이더가 처리하므로 프레임당 CPU 작업이 창 크기와 무관하다. 숨김 창 측정에서 paint+present는 512x384 0.164→0.142ms, 1920x1080 0.722→0.123ms, 3840x2160 2.411→0.131ms였다. 내부 16배 해상도의 프레임 루프 CPU는 두 게임에서 59~70% 줄었다. 1배에서는 렌더러가 RAM 출력을 유지하고 두 화면(각 256x192)만 올린다. 안전한 Vulkan 표시가 불가능하면 기존 QPainter 표시로 돌아간다. 공유 큐와 빌린 이미지는 `EmuInstance::vulkanRenderLock()`으로 RunFrame, 리셋, 정지, 상태 저장/불러오기와 직렬화한다. 제품 경로에서 쓰지 않던 Vulkan→OpenGL 전송 코드(551줄)는 넣지 않았다. 선형 필터는 QPainter와 채널당 최대 1/255 차이가 나고, nearest 출력은 동일하다. 근거는 `local-docs/vk-direct-display-2-20260925/`, `vk-display-prune-20260925/`.

**Sinc 보간(모드 6).** 모든 보간 모드는 믹서 샘플(약 32.7kHz)을 blip_buf에 계단 신호로 넘겨서, 모드와 관계없이 고역이 최대 −5.6dB 깎이고 이미지 억제가 4.6dB에 그쳤다. 새 Sinc 모드는 PCM/ADPCM 음성마다 48탭 Kaiser sinc 필터를 쓰고, 최종 스테레오 믹스를 다상 sinc 리샘플러로 호스트 출력률에 맞춘다. 기존 `tests/AudioSinc.cpp` 검사에서 통과대역 최악 −0.17dB, 사인 이미지 억제 78.3dB 이상, 구형파 91.8dB 이상이다. 전체 에뮬레이터 비용은 MinimumPhase보다 Solatorobo 25.6%, Black 16.2% 적고(A/A 약 3%), Gaussian보다 3.9%/13.2% 많다. 모드 0~5의 PCM은 두 게임에서 바이트 동일하다. Sinc를 쓴 저장 상태만 14.15로 올려 음성 히스토리를 저장한다. 런타임 AVX2/FMA 선택, SSE2, NEON, 스칼라 경로가 있고 스칼라 강제 검사가 통과한다. libc++에는 `std::cyl_bessel_i`가 없어 I0 급수를 직접 계산하며, Windows의 계수와 PCM은 바뀌지 않았다. `local-docs/audio-sinc-output-20260925/`.

**ARM64 JIT 블록 연결.** 1.1.181의 x64 정적 분기 블록 연결을 AArch64 백엔드에 옮겼다. 패치 바이트 저장은 백엔드별 `Compiler::PatchChainSite`로 옮겼고 x64는 같은 바이트를 쓴다. ARM64 가드는 `offsetof(NDS, ARM9Timestamp)`가 LDR 변위 범위를 넘어서 조용히 잘리던 문제를 주소 계산으로 고쳤다. qemu-aarch64 `^core-|^arm64-` 151/151, aarch64 네이티브 CI Core regressions 통과. x64 실행 파일의 두 게임 결과는 바이트 동일하다. ARM64 실측 속도는 없다. `local-docs/a64-block-link-20260925/`.

같은 라운드에서 채택하지 않은 것: 소프트웨어 3D 깊이 검사 함수 포인터 제거(정확하지만 −2.1%/−1.4%로 A/A 이하, `soft3d-depth-dispatch-20260925`). OpenGL 표시 경로 점검(`gl-window-scaling-audit-20260925`)에서는 창 크기에 비례하는 업로드나 읽기가 없고, 남은 비용은 창 전체 지우기, 텍스처 그리기, 스왑이었다. 빨리 감기 중 GL 표시 제한은 다음 후보다.

비공개 게임 두 개의 헤드리스 Software 1200프레임 ABBA 실행에서 1.1.181과 1.1.182의 최종 화면·누적 PCM·프레임버퍼 digest가 같았다.
