# 1.1.170 — ARM7 JIT 다중 레지스터 전송 타이밍 보정

2026-09-24. 이전 버전 1.1.169. 기본 배포 설정은 SDL2이며 SDL3는 `ENABLE_SDL3=ON` 선택형 빌드다.

ARM7 x64 JIT가 메인 RAM 스택으로 컴파일한 `LDM` 블록을 나중에 ARM7 WRAM 스택에서 재사용하면, 읽은 레지스터 값은 현재 스택을 따르지만 사이클은 이전 스택 비용을 유지했다. 같은 게스트 코드와 진입 시각의 게임 추적에서 캐시 블록은 24사이클, 새 추적은 13사이클이었고, 차이 11사이클은 다중 전송 하나에서 발생했다. 이번 변경은 실행 전 실제 전송 주소별 비용과 첫 주소의 메인 RAM 분류를 확인한다. 컴파일 당시와 다르면 부작용 전에 해당 명령 하나를 기존 해석기에서 실행한다. ARM9의 기존 다중 전송 검사 경로는 유지된다.

집중 회귀 검사는 여섯 레지스터 `LDMIA sp!`를 메인 RAM 스택에서 컴파일한 뒤 WRAM 스택으로 캐시 재사용하고, WRAM에서 새로 컴파일한 블록 및 해석기와 레지스터·SP·PC·CPSR·사이클을 비교한다. 수정 전 코어는 값과 상태가 같아도 사이클 `19/8/8`로 실패했고, 수정 후 집중 검사는 통과했다.

같은 비공개 게임 입력의 프레임 6001 기준/저장 후 JIT 리셋 비교에서는 두 경로의 화면 해시가 같고, 이전에 달랐던 ARM7 WRAM 바이트 `0x0380FF20`와 Timer5 재장전값이 일치했다. 그러나 타이머·ARM9를 포함한 저장 상태 차이는 남아 있어 **BV-17은 미해결**이다. 이 결과는 확인된 다중 전송 오류의 보정 범위이며, 전체 상태 동일성 또는 실제 기기 타이밍을 주장하지 않는다. 비공개 ROM, savestate와 원시 계측 파일은 배포하지 않는다.

빌드·검사·패키지·실제 첫 실행 결과는 검증 후 이 문서에 기록한다.
