# 1.1.194 — 선택형 Vulkan GPU 2D의 입력·스냅샷·대기 비용 감소

2026-09-28. 릴리스 소스 커밋은 e3c613e49270441a70e8db245f981822729a0c7a다. SDL3·SDL2 패키지와 플랫폼 CI 검증을 완료했다.

## 반영한 변경

- VRAM의 변경 비트가 가리키는 페이지만 검사한다. 변경 없는 줄의 페이지 표 복사와 전체 순회를 없애고, GPU override·부분 마지막 마스크·기존 불변 뷰·예산 실패의 원자성을 보존한다.
- OBJ가 꺼진 동안 불필요한 dirty 도출·VRAM flat 갱신을 건너뛴다. 다시 켤 때 한 번 전체 갱신하여 비활성 중 뱅크가 다른 용도로 갔다가 돌아온 경우도 반영한다. 엔진 전체 비활성의 기존 OBJ/mosaic 래치는 유지한다.
- GPU 입력은 매핑 가능한 장치 메모리, 장치 메모리+업로드 버퍼, 기존 호스트 메모리 대체 순으로 선택한다. 입력 버퍼는 기하급수적으로 확장해 반복 할당을 줄인다. 장치 메모리 경로에서도 스캔라인별 CPU 상태 스냅샷은 남는다.
- 캡처 없는 마지막 화면 묶음은 GPU에 제출하고 CPU가 VBlank를 처리한다. 첫 의존 작업·CPU readback·정지·리셋·배율 변경·소멸에서 완료하고 자원 수명을 유지한다. 캡처 명령이 있는 묶음은 Revision/Snapshot 계약 때문에 계속 동기로 완료한다.

## 성능과 한계

기본 설정은 여전히 CPU2D이며 GPU2D는 선택형/기본 false다. 이번 수치는 **1.1.193 GPU2D 대비**이며 기본 렌더링 경로의 속도 향상이 아니다. 플레이나 데스크톱 조작 없이 고정 부팅 구간을 headless로 실행했다.

## 정확성·배포 검증

- CPU 전용 스냅샷 회귀 통과. 같은 테스트가 기준 소스에서도 통과하며, private 차분의 7168캡처 및 측정 부하 57,344캡처에서 arena·뷰·재사용 digest가 완전히 같다.
- 기존 native2D event/batch/캡처 overlap·OBJ/texture/hires OBJ·scale/backend toggle 8검사 통과. 별도 disabled OBJ 재매핑 반례는 양 엔진 2048픽셀을 독립 SoftRenderer와 비교하고 CPU2D fallback 미실행을 확인했다.
- 실제 Radeon·RTX에서 매핑 장치 메모리/업로드 장치 메모리/호스트 대체의 세 경로를 각각 선택해 화면 98,304픽셀 일치 및 pending readback·Stop·Reset·SetScale·소멸을 확인했다. 강제 경로 검사는 메모리 부족의 실제 재현을 뜻하지 않는다.
