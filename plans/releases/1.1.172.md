# 1.1.172 — GPU3D 내부 폴리곤 클리핑 단축과 SDL3 오디오 재시도

2026-09-24. 이전 버전은 1.1.171이다. 기본 배포는 SDL2이고 SDL3는 `ENABLE_SDL3=ON` 선택형 빌드다.

GPU3D의 폴리곤에서 처리 대상 정점이 여섯 클리핑 평면 안에 모두 있으면, 불필요한 여섯 번의 클리핑 버퍼 순회를 건너뛴다. 원래 경로의 색상 양자화는 한 번 적용하고, 스트립에서 재사용한 정점과 경계·음수 W·`attribs=false` 경로는 기존 동작을 유지한다. SDL3 오디오 출력은 `SDL_ResumeAudioStreamDevice` 실패를 이제 `Start` 실패로 보고하고 복구 상태를 세운다. 재시도 성공 때만 실행 상태로 전환한다.

GPU3D 함수 경계의 격리된 차등 검사는 클리핑 23,216건과 폴리곤·정점 제출 79,440건에서 비교 대상 활성 상태 800,503,275바이트가 일치했다. Windows x64의 동일 생성 입력·9쌍 교대 측정에서 완전히 내부인 삼각형의 폴리곤 제출은 중앙값 144.14→54.79 ns/op, 내부/클리핑 50:50 입력은 167.09→113.13 ns/op였다. 반면 X/Z 클리핑, 원거리 거절, 음수 W 제출은 각각 쌍별 중앙값 기준 3.69%, 2.44%, 2.01%, 1.28% 느렸다. 실제 게임의 입력 분포와 전체 에뮬레이터 FPS는 측정하지 않았으므로 순성능 향상은 주장하지 않는다.

SDL3 더미 드라이버에 첫 resume 실패를 주입한 소스 직접 검사는 수정 전 첫 실패를 성공으로 보고하고 두 번째 호출에서 재시도하지 않던 것을 재현했다. 수정 후 첫 `Start`는 실패와 복구 필요를 보고했고 두 번째 `Start`는 실제 resume을 다시 호출해 성공했다. 실제 오디오 장치의 복귀·음질 수락은 이 검사에 포함되지 않는다. 별도의 오디오 보간 검토에서는 현재 코드의 구체적인 결함이 입증되지 않아 변경하지 않았다.

소스 커밋 `2ac3723cc211a9e8dc4a42d676bd659512109ea9`의 깨끗한 스냅샷에서 Windows UCRT64 Release를 SDL2·SDL3로 각각 빌드했다. SDL2 전체 CTest **1023/1023**, SDL3 오디오·입력 집중 CTest **48/48**을 통과했다. SDL3의 기존 프런트엔드 오디오 CTest 대상은 SDL2를 링크하므로 SDL3 출력 분기 검증 근거로 세지 않았다. 두 배포·패키징은 최종적으로 exit 0이고, 두 매니페스트의 소스 ID는 `28a7e7b94cd9331fbb2f3d4eb78b716436aac494b752ade19ad4bc46978a50e9`로 같다. 각 런타임 ZIP은 325개 파일이며 검사한 비공개 파일은 0개다. 기본 ZIP에는 SDL2 DLL만, 선택형 ZIP에는 SDL3 DLL만 있다. 다른 작업자의 수정된 `src/teakra/src/test_generator.cpp`는 커밋·소스 ZIP에 포함되지 않았다.
