# 1.1.221 — Sinc 일반 다운샘플 루프 분리

2026-09-29. SDL3·SDL2 패키지와 플랫폼 CI 검증을 완료했다.

## 변경

Sinc 일반 다운샘플 경로에서 16개 float 계수 생성과 double 정규화 합산을 별도 루프로 나눴다. 각 계수의 계산식과 float 반올림, 합산 순서, 16탭 dot 누적, 마지막 나눗셈을 유지한다. 새로운 공유 배열·할당·설정은 없다. 기존 정렬 위상 캐시와 고정 비율·무음 경로, 음질·저장 상태·버퍼 동작은 유지한다. 해당 계수 생성 루프의 자동 SIMD 벡터화는 확인되지 않았으므로 SIMD 개선이라고 부르지 않는다.

## 검증과 측정

기존 Sinc 이력 검사와 540개 출력의 캐시/대체 경로 추적은 자동 SIMD와 강제 scalar 각각 1.1.220의 서명과 일치했다. 무음/저장 상태 서명은 `f71a19652aed948a`, 캐시 추적은 native `7c35fd7e94c5c193`, scalar `67ebbc0d88f27d53`을 유지했다. 서로 다른 연산 경로 사이의 서명을 같게 만들지는 않는다.

실제 NDS SPU·믹서·48kHz PCM 출력을 사용하는 비영 PCM16 반복 입력 5개에서 전후 PCM 바이트가 같았다(합계 112,632개 s16 샘플). 워밍업 후 Mix·출력 읽기 비용을 실행 순서 교차로 7회 측정한 중앙값이다. ROM·BIOS·물리 오디오 장치를 사용하지 않았다.

| --- | --- | --- | --- |
| 384 / 512 / 16 / 8192 | 34.1274 | 32.0942 | 일반 경로 약 6.0% 감소 |
| 175 / 352 / 16 / 8192 | 43.2860 | 42.0139 | 일반 경로 약 2.9% 감소 |
| 127 / 512 / 16 / 8192 | 68.2889 | 65.3976 | 일반 경로 약 4.2% 감소 |
| 256 / 512 / 16 / 8192 | 20.5632 | 20.5234 | 캐시 경로 약 0.2% 감소 |
| 512 / 512 / 16 / 8192 | 18.7378 | 18.8506 | 고정 비율 약 0.6% 증가 |

사용 중인 Windows PC의 제한된 합성 입력 결과이며 작은 차이를 확정적인 개선이나 회귀로 일반화하지 않는다. 별도 함수 측정에서는 캐시 대조군이 약 4% 느리게 관측된 결과도 보존했다. 16탭 단위로 경계 검사를 모으는 별도 실험안은 일반 조건에서 약 11~15% 느려 채택하지 않았다. 표의 개선은 전체 게임 FPS·물리 입력/오디오 지연·음질 개선율이 아니다. 장기 청취나 틱 노이즈 완전 해결을 확인하지 않았다.

전체 회귀는 CI에서만 수행한다. Windows x64·ARM64, Ubuntu, macOS, BSD, Core regressions CI가 모두 통과했다. x86 JIT ON/OFF·ARM64의 기존 Sinc 이력/scalar 검사를 포함한다. 로컬 전후 PCM 일치와 다른 플랫폼의 현행 회귀 통과는 서로 다른 검증이다.
