# 1.1.185 — 소프트웨어 2D 렌더링과 Windows 배포 준비 비용 감소

2026-09-26. 이전 버전은 1.1.184다. 소스 커밋은 `74a9e616bde44665707c19f0ef23d6dfc6a4d90b`이며, SDL3·SDL2 패키지를 검증했다. 플랫폼 CI가 모두 통과했다.

GPU2D는 텍스트 배경의 타일 행을 한 번 읽고, 완전히 투명한 행의 구간을 건너뛴다. 캡처하지 않는 native 픽셀의 저장을 직접 수행하고, 캡처 OBJ 배율이 0이면 쓰이지 않는 캡처 작업을 생략한다. 픽셀 색 변환·우선순위·그리기 순서·캡처 결과를 유지한다. `d95dca77`.

Linux x86-64, 소프트웨어 렌더러, JIT fastmem을 끈 300프레임 Lackey 측정에서 실행 명령어 수가 Solatorobo **2.546%**, Black **1.377%** 줄었다. Windows의 1200프레임 교대 실행 4회에서는 시간 중앙값이 각각 0.524%, 3.603% 줄었지만, 기준본 반복의 변동 폭도 4.50%, 5.19%였다. 이번 실행에 대응하는 별도 A/A 측정은 없으므로 **FPS 향상을 입증한 수치로 제시하지 않는다**. 명령어 수 감소와 출력 일치, 제한된 실행 시간 비교를 근거로 채택했다.

기존 두 게임의 화면·PCM·저장 상태 비교가 일치했다. 직접 렌더링 함수를 호출하는 비공개 검사 도구에서 행별 3D 상태 초기화가 빠진 문제를 고친 뒤, 기준본과 후보 모두 정상 종료했고 7680개 텍스트·25600개 비트맵·800개 3D 조건의 총 280872960바이트 출력이 완전히 일치했다. 검사 도구의 부분 출력이 같았지만 비정상 종료했던 이전 결과는 성공 근거에서 제외했다. 근거: `local-docs/s2d-complete-20260926/`.

Windows 배포 도구는 패키지마다 실행하던 파일 목록·버전 조회를 묶어 pacman 호출을 3회로 줄였다. 이전 SDL3 배포의 소유 패키지는 86개였다. 집중 검사 7개와 실제 패키지 7개의 라이선스 선택·버전 결과 비교를 재사용했다. 배포 전체 시간의 개선율은 따로 측정하지 않았다. `264f227d`.

Windows CI의 vcpkg 캐시는 러너 이미지 버전과 의존성 입력을 키에 포함한다. 러너의 컴파일러가 바뀌었는데도 오래된 캐시의 정확 일치로 판정되어, 재빌드한 패키지를 새로 저장하지 못하던 경우를 처리한다. 이번 ARM64 CI에서 기존 패키지 30개 복원과 새 이미지 버전 키로 저장한 기록을 확인했다. 새 키를 다음 실행에서 재사용한 속도는 아직 측정하지 않았다. `c79340ef`.

ARM7 소유 참조 변경은 명령어 감소가 1% 미만이고 실행 시간 차이가 A/A 변동 안에 있어 채택하지 않았다. 소프트웨어 3D의 RGB 산술 결합은 생성 코드가 늘어나 실행 시간 검사를 추가하지 않고 제외했다.

필수 회귀·플랫폼 검사는 CI에서 수행하며 같은 변경의 로컬 전체 검사를 반복하지 않는다. Core regressions는 GCC 14·Clang 18 ASan/UBSan 독립 회귀, 전체 코어 빌드와 x64 JIT ON/OFF·ARM64의 선택된 CPU/DSP 실행 검사를 통과했다. 이 결과를 모든 프런트엔드 검사를 실행한 것으로 취급하지 않는다. 게임 플레이·실기 화면·청취·저사양 기기의 모든 구간은 이번 검증 범위에 포함하지 않는다.
