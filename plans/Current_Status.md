# 현재 개발 상태 — 1.1.203

2026-09-29. 코드와 빌드의 기준 경로는 F:/melonDS다. [1.1.203 릴리스 기록](releases/1.1.203.md)에 소스·검증 범위를 기록한다. SDL3·SDL2 패키지와 Windows·Ubuntu·macOS·BSD·Core regressions CI가 모두 통과했다.

1.1.203은 Vulkan의 불투명 픽셀 알파 바이트에 경계·커버리지 속성을 가역적으로 넣어 별도 속성 타일 버퍼를 제거한다. 타일 임시 버퍼 범위가 약 1/3 줄고 일반 유효 픽셀의 중간 저장은 12→8바이트가 된다. 깊이·그림자·반투명 처리와 GL 표현은 유지한다. GPU 픽셀 대조와 3배율 캡처 검사가 통과했다. 정수 패킹 연산이 추가되므로 FPS 개선은 단정하지 않는다. 사용 중인 PC의 다른 프로그램을 끄거나 시간 측정값을 성능 근거로 채택하지 않았다. Vulkan GPU2D는 기본 비활성이다.

## 성능 수치의 범위

- 1.1.203은 속도 대신 버퍼 범위와 셰이더 접근 제거를 검증했다. 일반 알파 통과 fragment의 저장은 12→8바이트이고, 속성을 소비하는 불투명 fragment의 4바이트 읽기도 사라진다. 캐시에 따라 실제 외부 메모리 트래픽은 다르며 패킹의 정수 연산 비용이 추가된다. 현재 PC 사용 부하를 통제하지 못하므로 FPS 향상률을 주장하지 않는다.

- 1.1.202의 x64 RSB·RSC 계산부는 시프트 없는 Operand2에서 목적지가 독립이면 3→2명령, 목적지가 Operand2와 같고 Rn과 다르면 3→1명령이다. 목적지와 Rn이 겹치거나 이미 시프트 결과를 임시 레지스터에 둔 경우에는 명령 수가 줄지 않는다. carry 준비·플래그 회수는 유지하며 게임 FPS 수치로 환산하지 않는다.

- 1.1.200의 x64 MUL 계산부는 MOV·IMUL·MOV 3개에서 목적지가 독립이면 2개, 피연산자와 같으면 IMUL 1개가 된다. Thumb MUL도 1개이며 기존 플래그 처리·guest 사이클 계산은 유지한다. MLA는 목적지가 피연산자와 겹치고 누산기와 다를 때 3→2개다. 이는 emitter의 명령 수 감소이며 게임 속도 개선률은 아니다.

- 1.1.201은 저장 지점·dispatch 감소와 제한된 최종 GPU 확인만 거쳤고 시간 개선은 채택하지 않았다. A/B/A Radeon 3D는 7.826371, 6.898131, 6.913249ms로 기준 A끼리의 변동이 컸고, RTX 3D는 0.246488, 0.242914, 0.252759ms였다. 두 GPU의 Solatorobo 4배율 시작 1200프레임 최종 framebuffer SHA는 1.1.200과 같다. 이 수치를 FPS 향상률로 환산하지 않는다. 근거: local-docs/graphics-201/final-gpu-attribution.json.

- 1.1.197의 GCC x64 출력에서 dense 스테레오 계수 벡터 읽기는 두 Dot 호출의 8회에서 한 호출의 4회로 줄었다. JIT의 해당 3명령 산술은 LEA 1개 또는 목적지 직접 계산 1~2개로 줄어든다. 이는 명령·메모리 작업량 감소이며 FPS 수치가 아니다. 오디오 별도 프로세스 측정은 A/A 변동이 컸고 동일 프로세스 비교도 중앙 패닝 대조군에서 변화가 보여 시간 개선률을 채택하지 않았다.

- 1.1.196의 **1.1.195 GPU2D 대비** CoD 4배율 시작 1200프레임(첫 240 제외) 평균 시간 변화는 세 쌍 중앙값 RTX −59.45%, Radeon −54.36%다. p95도 모든 쌍에서 감소했다. RTX 같은 바이너리 A/A 한 쌍은 +0.57%. 같은 후보 소스의 GPU2D/CPU2D 단회 직접 비교는 CoD RTX −31.0%·Radeon −39.3%, Solatorobo RTX −32.2%·Radeon −22.5%다. Solatorobo RTX 1배율은 이전 버전 대비 단회 +0.94%로 개선을 입증하지 못했다. 근거: local-docs/native2d-cost-196/measurement.json. 아래 이전 버전 기록은 당시 결과다.

- 1.1.195는 **1.1.194 GPU2D 대비** Solatorobo 4배율 1200프레임(첫 240 제외)의 평균 프레임 시간을 세 쌍 모두 줄였다. 중앙값 RTX 5080 −30.91%, Radeon 내장 GPU −7.19%, 같은 바이너리 Radeon A/A 한 쌍 +0.16%다. 같은 소스의 GPU2D/CPU2D 직접 비교에서는 Solatorobo 4배율이 RTX 약 −22.7%, Radeon 약 −12.6%였지만 CoD는 각각 약 +108.9%, +35.0%로 느렸다. 이 직접 비교는 각 조건 한 쌍이며 기본 활성화나 전체 장면의 우위를 주장하지 않는다. 근거: local-docs/native2d-reuse-195-20260928/measurement.json.

- 1.1.194의 CoD 4배율 시작 1200프레임(첫 240 제외)은 기존 GPU2D 대비 세 쌍 모두 평균 시간이 줄었다. 중앙값은 RTX 5080 −12.84%, Radeon 내장 GPU −6.09%다. Radeon 같은 바이너리 A/A 한 쌍의 차이는 +3.74%로, 적은 반복 수의 변동 한계도 남긴다. VRAM 스냅샷 CPU 작업은 별도 합성 부하 다섯 쌍에서 약 6.0% 감소했다. 기본 CPU2D의 FPS 향상이나 모든 게임/기기의 이득으로 환산하지 않는다. 근거: local-docs/vulkan2d-194-20260928/measurement.json 및 native2d-memory/measurement.md.

- 원본과 직접 비교한 가장 최근 기록은 **1.1.180 대 포크 기준 원본**이다. Ryzen 7 9800X3D/Windows, 소프트웨어 렌더러, 두 게임의 시작 1200프레임에서 실행 시간은 JIT+fastmem 기준 Solatorobo 약 3.5%, Black 약 10.1% 줄었다. 인터프리터는 각각 약 3.9%, 5.7%였다. 같은 바이너리 A/A 대조를 포함한다. 다만 Black/JIT은 마지막 화면의 진행도가 다르고, 오디오 해시도 포크의 정확도 변경으로 원본과 다르므로 완전히 동일한 연산의 속도 비교는 아니다. 다른 장면·저사양 기기·GPU 렌더러·1.1.186 전체의 향상률로 확대하지 않는다. 근거: `local-docs/upstream-speed-20260925/result.md`.
- Sinc의 [1.1.182 측정](releases/1.1.182.md)은 같은 두 게임에서 MinimumPhase보다 전체 에뮬레이터 비용이 약 16~26% 적었다. Gaussian보다는 약 4~13% 많았다. 신호 품질 검사는 통과대역 최악 약 −0.17dB와 사인 이미지 억제 78.3dB 이상을 확인했다. 이 수치가 청취 평가를 대신하지 않는다.
- 1.1.184의 스케줄러·ARM9 변경은 각각 약 1~2.3%의 **실행 명령어 수** 감소를 보였다. fastmem을 끈 Linux 측정이며, 두 값을 더해 FPS 향상률로 해석하지 않는다. 자세한 조건은 해당 릴리스 기록을 따른다.

- 1.1.185 GPU2D 변경은 같은 두 게임의 Linux 300프레임, fastmem OFF 측정에서 실행 명령어 수를 2.546%, 1.377% 줄였다. Windows 시간 비교는 반복 변동보다 작은 차이여서 FPS 향상률로 제시하지 않는다. 실제 저사양 기기의 전체 장면을 측정한 결과는 아니다.

- 1.1.186은 32개 텍스처와 clear bitmap을 갱신하는 20프레임에서 GPU 제출이 각 배율당 37회에서 19회로 줄었다. 1배율·3배율의 native 화면은 독립 소프트웨어 렌더러와 바이트 단위로 일치했다. 업로드가 드문 장면의 이득은 작을 수 있으며 FPS 향상률은 측정하지 않았다.

- 1.1.187의 native 2D 기반은 활성화되지 않았다. 확인된 것은 private 진입점과 고정 코퍼스의 정확성 대조(AMD 1회)이며 FPS·일반 성능으로 확대하지 않는다. 근거: `local-docs/vulkan-2d-native-20260926/integration/result.md`, `hires-lcdc.json`, `hires-bg.json`, `hires-texture.json`.

- 1.1.188 GPU 2D는 RTX 5080에서 Pokemon Black 1배율 중앙값 818→1256µs, Solatorobo 846→1442µs처럼 CPU 2D보다 느렸다. 그래서 기본값을 바꾸지 않았다. 근거: `local-docs/gpu2d-activation-20260927/result.md`.

- 1.1.189 Vulkan 3D 대기 겹치기는 5라운드 교차 측정에서 CoD 1배율 RTX 1140→991µs, Radeon 2배율 2621→2252µs, Solatorobo 1배율 RTX 818→746µs로 줄었다. Pokemon Black처럼 3D가 적은 장면은 변동 범위 안이었다. 근거: `local-docs/vk1x-189-20260927/result.md`.

- 1.1.190 소프트웨어 3D 정리는 Solatorobo 부팅 이후 300프레임 구간의 실행 명령어 수를 9.59→9.20십억 개(−3.99%)로 줄였다. fastmem을 끈 Linux callgrind 측정이다. 근거: `local-docs/soft3d-189-20260927/result.md`.

- 1.1.191 Vulkan 합성 대기 겹치기는 7라운드 교차 측정에서 CoD 2배율 Radeon 2457→2176µs, RTX 1512→1373µs, CoD 4배율 Radeon 4638→4405µs로 줄었다. 근거: `local-docs/vkdisplay-189-20260927/result.md`.

- 1.1.192 빈 타일 생략은 Radeon 4배율 Solatorobo의 GPU 3D 시간을 10.15→7.20ms, 평균 프레임 시간을 8348→7607µs(9쌍 모두 감소)로 줄였다. CoD는 변화가 없었다. 근거: `local-docs/vkraster-189-20260927/result.md`.

- 1.1.193 MinimumPhase의 16채널 희소 입력·mixer interval 512 커널은 쌍별 중앙값 기준 스레드 사이클이 17.47% 줄었다(5/5쌍, A/A 절대 중앙값 1.88%). 전체 게임 FPS나 새 명령 집합의 효과가 아니다. dense·interval 352에서는 개선을 확정하지 않았다. OpenGL은 6배치×2필터에서 실제 clear 감소와 픽셀 일치를 확인했지만 프레임 시간 이득은 측정하지 않았다.

- 보류한 Vulkan 픽셀 사전검사는 Radeon Solatorobo 4배율 GPU 3D 시간 −4.57%였지만 RTX 대조는 +4.92%였다. 화면은 같아도 공통 성능 이득이 없어 기본 경로에 넣지 않았다. 소프트웨어 2D 인라인 후보도 시간 변동이 커 채택하지 않았다. 근거: local-docs/opt193-20260928/의 각 parent-result와 timing-summary.
